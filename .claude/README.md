# Hi Kiki 自动化 Skills 体系

**创建时间**: 2026-03-04
**状态**: ✅ 已完成

---

## 🎯 这是什么？

一套帮助你自动化开发 Hi Kiki 三端项目（移动端 + 后端 + 管理后台）的工具体系。

**核心理念**：定义一次，三端通用 → 自动生成代码 → 你只需补充 20% 的业务逻辑

---

## 📦 包含什么？

### 4 个 Skills（自动化工具）

```
/orchestrator      - 项目总指挥（分析需求，分解任务）
/contract-manager  - 契约管理（定义数据模型和API）
/code-generator    - 代码生成（从契约自动生成三端代码）
/task-executor     - 任务执行（批量自动执行任务）
```

### 核心概念：契约优先开发

```
1. 写契约（YAML文件）
   ↓
2. 自动生成代码（后端 + 前端 + 数据库）
   ↓
3. 补充业务逻辑（你只需要做 20%）
   ↓
4. 完成！
```

## ❓ 常见问题

### Q: 生成的代码需要修改吗？
A: 需要补充 20% 的业务逻辑（权限、验证、特殊逻辑等），80% 的框架代码已自动生成。

### Q: 如何定义契约？
A: 使用 `/contract-manager` 或手动编写 YAML 文件，参考 `contracts/scene.contract.yaml`。

### Q: 出错了怎么办？
A: 查看入手教程的常见问题部分，或直接问我。

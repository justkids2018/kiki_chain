## 常见问题

### Q1: 编辑时看不到 JSON 数据
**原因**: 可能是旧场景（在添加 items_data 字段之前创建的）
**解决**: 重新编辑该场景，粘贴 JSON 数据并保存

### Q2: 提示"JSON 格式错误"
**原因**: JSON 格式不正确（缺少逗号、括号等）
**解决**: 使用 JSON 验证工具检查格式，或复制示例数据

### Q3: 保存后物品数为 0
**原因**: items_data 为空或格式不是数组
**解决**: 确保粘贴的是 JSON 数组 `[...]`，不是对象 `{...}`

### Q4: 前端显示空白
**原因**: 浏览器缓存
**解决**: 强制刷新页面 (Ctrl+Shift+R)

# 场景 JSON 数据显示问题排查

## 问题描述
编辑场景时，"物品数据 JSON"文本框没有显示数据。

## 排查步骤

### 1. 检查后端是否返回了 items_data

打开浏览器开发者工具（F12），切换到 Network 标签：

1. 在场景管理页面，点击"编辑"按钮
2. 查看网络请求，找到 `GET /api/v1/admin/scene/scenes` 请求
3. 查看响应数据，确认是否包含 `items_data` 字段

**预期响应**：
```json
{
  "success": true,
  "data": {
    "scenes": [
      {
        "id": "scene_xxx",
        "name": "动物世界",
        "items_data": [...],  // 应该有这个字段
        ...
      }
    ]
  }
}
```

### 2. 检查前端是否正确读取

在浏览器控制台（Console）中，输入：
```javascript
// 查看场景列表数据
console.log(scenes.value)
```

检查每个场景对象是否有 `items_data` 字段。

### 3. 测试创建新场景

1. 点击"新建场景"
2. 填写基本信息
3. 在"物品数据 JSON"中粘贴以下测试数据：
```json
[{"type":"chinese","id":"test_01","index":1,"text":"测试","text_pinyin":"cè shì","text_english":"Test","coordinate":[{"x":100,"y":100}]}]
```
4. 点击"确定"保存
5. 刷新页面
6. 再次点击"编辑"该场景
7. 查看"物品数据 JSON"文本框是否显示数据

### 4. 检查数据库

连接数据库，查询场景数据：
```sql
SELECT id, name, items_data FROM scenes WHERE id = 'scene_xxx';
```

确认 `items_data` 字段是否有数据。

## 可能的原因

### 原因1：后端没有返回 items_data
- **解决方案**：已修复，后端 SceneDto 已添加 items_data 字段

### 原因2：前端 Scene 接口类型不匹配
- **检查**：`kiki_admin/src/api/scenes.ts` 中的 Scene 接口是否有 `items_data` 字段
- **解决方案**：已添加 `items_data?: any` 字段

### 原因3：编辑时没有正确读取
- **检查**：`handleEdit` 函数中是否正确读取了 `row.items_data`
- **当前代码**：
```typescript
itemsDataText.value = row.items_data ? JSON.stringify(row.items_data, null, 2) : ''
```

### 原因4：数据库中没有数据
- 如果是旧数据（在添加 items_data 字段之前创建的），则 items_data 为 null
- **解决方案**：重新编辑场景，添加 JSON 数据

## 临时解决方案

如果编辑时看不到数据，但想查看场景的物品数据：

1. 使用 API 直接查询：
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:8081/api/v1/admin/scene/scenes/SCENE_ID
```

2. 或者在浏览器控制台中：
```javascript
// 假设已经获取了场景列表
const scene = scenes.value.find(s => s.id === 'scene_xxx')
console.log(JSON.stringify(scene.items_data, null, 2))
```

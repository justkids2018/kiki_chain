# Hi Kiki - 用户登录功能需求

> 版本：v1.0 | 日期：2026-01-18 | 状态：✅ 已确认

## 功能说明

实现手机号+密码登录，支持注册、登录、自动登录、退出登录。

## 核心流程

### 注册
```
填写：手机号(11位) + 密码(6-20位) + 昵称(可选)
 ↓
注册成功 → 自动登录 → 跳转首页
```

### 登录
```
填写：手机号 + 密码
 ↓
登录成功 → 保存Token(7天有效) → 跳转首页
```

### 游客模式
- 可跳过登录直接使用
- 数据仅存本地
- 登录后可选择绑定游客数据

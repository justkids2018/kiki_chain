## 建议的迁移方案

### 方案 1：渐进式迁移（推荐）

**优点**：风险低，不影响当前工作流
**步骤**：
1. 新文档全部放在 `docs/` 下
2. 需要更新旧文档时，顺便迁移到 `docs/`
3. 最后统一清理空的 `doc/` 目录

### 方案 2：一次性迁移

**优点**：快速统一，目录清晰
**步骤**：
1. 按功能模块将 `doc/` 下内容迁移到 `docs/` 对应目录
2. 将子项目 `doc/` 迁移到各自的 `docs/`
3. 更新所有文档引用路径
4. 删除旧的 `doc/` 目录

**风险**：可能影响现有脚本或引用路径

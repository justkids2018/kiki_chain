## 🔄 完整用户流程（闭环验证）

### 新用户流程
```
1. 打开 App → WelcomePage（检查登录状态）
2. 未登录 → 显示欢迎界面 → 点击"游客模式"
3. 进入 HomePage（一级分类列表）
4. 点击"日常生活"分类 → CategoryDetailPage（二级场景列表）
5. 点击"上学"场景 → InteractiveImagePage（学习详情页）
6. 点击热区学习物品 → 显示汉字笔顺 + 语音

8. 分享到微信朋友圈 → 好友扫码注册
9. 双方获得 7 天会员奖励 ✅
```

### 老用户流程
```
1. 打开 App → 自动登录 → HomePage
2. 看到学习进度（星级显示）
3. 继续学习未完成的场景
4. 查看"我的"页面 → 学习统计 + 邀请记录
5. 分享邀请链接 → 获得更多奖励 ✅
```

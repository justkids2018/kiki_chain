# 成长地图分栏学习入口需求

## 目的

在保留现有成长地图视觉风格的前提下，让横屏设备同时呈现成长路径与当前学习卡片，帮助儿童一眼看清当前场景并直接进入学习。

## 已确认需求

1. 页面采用横屏左右分栏，左侧为成长地图，右侧为当前选中节点对应的单张学习卡片。
2. 左侧保留现有森林背景、树枝路径、圆形节点和底部角色素材，不重新设计视觉语言。
3. 学习顺序从上到下排列。已学习或较早节点位于上方，后续节点位于下方。
4. 当前选中节点进入页面时定位在左侧可视区域中部。
5. 点击左侧节点后，节点成为当前选择，右侧卡片同步切换，不立即进入学习。
6. 点击右侧卡片后，进入现有互动学习页面。
7. 右侧只展示一张完整卡片和必要的场景名称，不展示词条数量、统计面板或其他卡片。
8. 继续复用现有场景加载、上次选择恢复、错误态、空状态与学习页导航逻辑。

## 验收标准

1. 横屏首屏能同时辨认成长地图和完整学习卡片。
2. 默认恢复的节点位于左侧区域中部，右侧展示同一场景。
3. 点击任意可用节点只切换选择，不直接跳转。
4. 点击右侧学习卡片能够进入对应场景。
5. 场景顺序视觉上从上到下递增，滚动方向符合常规列表直觉。
6. 页面不出现重复卡片、词条数量或复杂学习统计。
7. 加载、失败、空数据和网络图片失败时仍有可用反馈。

## 不在本次范围

- 不新增或修改 API。
- 不新增真实学习进度字段。
- 不调整场景解锁或 VIP 规则。
- 不重做成长地图素材与角色形象。
- 不修改互动学习卡片内部功能。

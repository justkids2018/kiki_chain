# 箭头组件规范

这个文件只定义标签到物体之间的连接箭头。

## 必须规则

- 所有箭头必须使用同一套组件样式
- 箭头必须略粗于发丝线，但仍然精致
- 箭头主体必须圆润、干净、平滑
- 箭头头部必须小巧圆润，不能尖锐技术感过强
- 箭头必须从卡片边缘自然延伸出来，不能断开
- 箭头必须短、准、清楚
- 箭头必须精准落在目标物体边界或主体关键位置
- 箭头之间不能交叉

## 落点精度规则（核心）

- 箭头必须**触碰到**目标物体的本体，不能停在物体旁边的空白区域
- 对于有独特形态的物体，箭头应指向最能代表该物体的位置：
  - 箭头落在物体的主体中心或最明显的轮廓边缘
  - 例：指向课桌→落到桌面板，指向讲台→落到讲台台面或正面，指向粉笔→落到粉笔本身的柱体上
- 距离相近的两个物体，各自的箭头必须从不同方向切入，确保没有视觉交叉或混淆
  - 例：讲台和课桌相邻时，讲台箭头从左上切入讲台台面，课桌箭头从右下切入课桌桌面
- 箭头长度控制：从卡片边缘到物体边缘，短且直接，不应有超过物体宽度的大弯路

## 颜色逻辑

- 箭头必须统一使用同一套场景强调色系
- 不使用默认灰色箭头
- 箭头颜色应与场景协调，但必须稳定、易读
- 可使用柔和天蓝、低饱和青蓝、或儿童友好的场景强调色

## 造型方向

- 优先使用柔和轻弯曲箭头
- 只有更清晰时才使用短直线
- 可加极轻微阴影或边缘分离，提升可读性

## 禁止项

- 禁止丑陋的大弧线箭头
- 禁止 boomerang 式粗大连接线
- 禁止箭头停在物体旁边造成歧义（必须触碰到物体本体）
- 禁止箭头乱飞、过长、过粗
- 禁止两个相邻物体的箭头交叉或方向相同造成混淆

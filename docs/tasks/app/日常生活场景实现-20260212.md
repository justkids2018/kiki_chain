## 📋 任务概述

实现 6 个日常生活场景的完整互动学习功能，每个场景包含 12 个物品，提供中英文学习、TTS 发音、汉字笔画动画等完整功能。

这是 Sprint 1 的核心任务，完成后将为儿童提供丰富���日常生活场景学习内容。

## 🎯 任务目标

为以下 6 个场景创建完整的互动学习数据：
1. 早餐时间 (Breakfast Time)
2. 准备上学 (Getting Ready for School)
3. 帮妈妈做饭 (Helping Mom Cook)
4. 看电视时间 (TV Time)
5. 睡前准备 (Bedtime Preparation)
6. 周末打扫房间 (Weekend Room Cleaning)

每个场景需要：
- 创建场景互动数据 JSON 文件
- 准备或标注场景图片资源
- 定义 12 个物品的热点区域
- 配置 TTS 发音数据
- 添加汉字笔画动画数据
- 测试所有交互功能

**Step 1: 创建 JSON 数据文件**
```json

  "sceneId": "daily_breakfast",

      "id": "breakfast_001",

        "type": "rect",
        "x": 50,
        "y": 300,
        "width": 400,
        "height": 200
      },
      "audioUrl": "assets/audio/table.mp3",
      "character": "桌",
      "strokes": []
    }
    // ... 其他 11 个物品
  ]
}
```

**Step 2: 准备图片资源**
- 场景图片：`assets/images/scenes/daily_breakfast.png`
- 尺寸建议：1920x1080 或更高
- 风格：儿童友好、色彩鲜艳

**Step 3: 标注热点区域**
- 使用图片编辑工具标注每个物品的位置
- 记录坐标：x, y, width, height (矩形) 或 centerX, centerY, radius (圆形)
- 确保热点区域不重叠

**Step 4: 配置音频数据**
- 中文音频：`assets/audio/zh/table.mp3`
- 英文音频：`assets/audio/en/table.mp3`
- 拼音音频：`assets/audio/pinyin/zhuo_zi.mp3`

**Step 5: 添加笔画数据**
- 为关键汉字添加笔画顺序数据
- 使用 stroke_order_animator 库的数据格式

**Step 6: 测试验证**
- [ ] JSON 文件格式正确
- [ ] 所有热点区域可点击
- [ ] 中英文发音正常
- [ ] 汉字笔画动画正常
- [ ] 物品信息显示完整

6. **第六优先**: 周末打扫房间（周末场景）

### 并行开发策略
- 可以同时准备多个场景的数据
- 建议先完成 2-3 个场景，测试验证后再继续
- 使用模板化的方式提高效率

### 质量保证
- 每完成一个场景立即测试
- 保持数据格式一致性
- 注意热点区域的准确性
- 确保儿童友好的内容

## 📝 注意事项

1. **数据一致性**: 所有场景使用相同的 JSON 结构
2. **热点精度**: 热点区域要准确，避免误触
3. **内容适龄**: 所有内容适合 3-8 岁儿童
4. **文化适应**: 考虑中国儿童的日常生活习惯
5. **资源优化**: 图片和音频文件大小要合理
6. **可扩展性**: 预留扩展空间，便于后续添加更多场景

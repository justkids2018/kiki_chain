# 吃饭喝水啦 — 入学准备100字学习卡片 Prompt

> 分类：入学准备100字
> 主题序号：7.6
> 目标：在午餐/点心场景中认识常见食物和餐具

---

```text
**吃饭喝水啦** (主题): Hi Kiki

### I. Canvas & Style Lock
- Exact 1024x1024 square
- Premium miniature toy lunch table
- Warm, clean, healthy, low-age friendly

### II. Scene Background
Create a child lunch table scene with simple food and tableware. Kiki and Yuki are having a gentle snack/lunch. Mimi sits nearby watching. Make every food item clear and separate.

### III. Character Cast
Use Mimi + Yuki + Kiki.

### IV. 10 Target Vocabulary Objects
- [shuǐ] / 水 / Water (/ˈwɔːtər/)
- [fàn] / 饭 / Rice (/raɪs/)
- [mǐ] / 米 / Rice Grain (/raɪs ɡreɪn/)
- [miàn] / 面 / Noodles (/ˈnuːdəlz/)
- [cài] / 菜 / Vegetables (/ˈvedʒtəbəlz/)
- [guǒ] / 果 / Fruit (/fruːt/)
- [niú nǎi] / 牛奶 / Milk (/mɪlk/)
- [wǎn] / 碗 / Bowl (/boʊl/)
- [sháo] / 勺 / Spoon (/spuːn/)
- [chī] / 吃 / Eat (/iːt/)

Object placement map:
1. 水 — clear cup of water.
2. 饭 — bowl of cooked rice.
3. 米 — small rice jar or rice grains in a transparent cup, separate from cooked rice.
4. 面 — small bowl of noodles.
5. 菜 — green vegetables on plate.
6. 果 — fruit pieces on plate.
7. 牛奶 — small milk carton or cup.
8. 碗 — empty or serving bowl with clear rim.
9. 勺 — spoon beside bowl.
10. 吃 — Kiki eating action with spoon near mouth.

Critical placement rules:
- 饭 and 米 must be visually different: cooked rice in bowl vs dry rice grains.
- 水 and 牛奶 must be different containers/colors.
- 吃 must point to eating action, not random food.

### V. Label Cards
- [shuǐ] / 水 / Water
- [fàn] / 饭 / Rice
- [mǐ] / 米 / Rice Grain
- [miàn] / 面 / Noodles
- [cài] / 菜 / Vegetables
- [guǒ] / 果 / Fruit
- [niú nǎi] / 牛奶 / Milk
- [wǎn] / 碗 / Bowl
- [sháo] / 勺 / Spoon
- [chī] / 吃 / Eat

### VI. Arrows
- 水 arrow -> lands on water cup.
- 饭 arrow -> lands on cooked rice bowl.
- 米 arrow -> lands on dry rice grains.
- 面 arrow -> lands on noodles.
- 菜 arrow -> lands on vegetables.
- 果 arrow -> lands on fruit.
- 牛奶 arrow -> lands on milk carton/cup.
- 碗 arrow -> lands on bowl body.
- 勺 arrow -> lands on spoon body.
- 吃 arrow -> lands on eating pose.

### VII. Branding Badge
- Top-right corner: Hi Kiki

### VIII. Production Notes
- Can reuse lunch-table composition from existing school lunch cards, but keep vocabulary simpler.
```

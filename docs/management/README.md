## 🔄 使用流程

### 每次开发前

1. 查看 `PROJECT_STATUS.md` 了解当前进度
2. 查看 `TASK_LOG.md` 了解上次完成情况
3. 确定本次要做的任务

### 开发过程中

1. 在 `TASK_LOG.md` 记录执行过程
2. 遇到问题记录到"遇到的问题"
3. 完成任务更新状态

### 开发完成后

1. 更新 `TASK_LOG.md` 的完成情况
2. 更新 `PROJECT_STATUS.md` 的进度
3. 规划下次执行计划

## 📋 任务管理

### 任务池

**路径**: `../tasks/`

- **TASK_BOARD.md** - 任务看板
- **backend/** - 后端任务
- **app/** - 移动端任务
- **admin/** - 管理后台任务

### 任务优先级

- **P0**: 必须完成（阻塞其他工作）
- **P1**: 重要（影响核心功能）
- **P2**: 可选（优化和增强）
- **P3**: 低优先级（未来考虑）

# Kiki漫游 · 想象力教育产品需求文档（PRD v1.1｜含时间计划）

> 创建时间：2025年10月31日 · 想象力教育产品需求文档（PRD v1.1｜含时间计划）

---

## 🎯 一、项目愿景与使命

> 让孩子通过 AI 与绘画表达想象力，用英语讲述自己的世界，并通过区块链留下成长印记。

**Kiki漫游** 不只是一个学习应用，而是一个儿童创造力教育平台。它以 **AI + 绘画 + 语言表达 + 区块链确权** 为核心，让 5–10 岁孩子：

- 从图像和故事出发，激发“想象力”；
- 用自己的声音、语言和色彩“表达”；
- 把创造的世界永久留痕在链上，形成“成长档案”。

## 📅 二、项目时间计划（MVP周期：12周）

| 阶段 | 周期 | 目标 | 核心成果 |
|------|------|------|-----------|
| **W1–W2：项目初始化** | 第1–2周 | 明确需求、确定架构 | PRD冻结版 + 技术栈确认 + 任务分配 |
| **W3–W4：AI内容生成链路** | 第3–4周 | 打通Dify生成图像与文本 | 可生成个性化图像+英语短句 |
| **W5–W6：前端交互基础** | 第5–6周 | 实现Flutter上传、展示、绘画交互 | 孩子可完成“上传→生成→涂色”完整体验 |
| **W7–W8：后端与数据存储** | 第7–8周 | 建立Rust服务 + PostgreSQL 数据流 | 可存储作品、用户信息、生成记录 |
| **W9–W10：区块链确权模块** | 第9–10周 | 集成Substrate Pallet | 作品上链成功，生成哈希可查询 |
| **W11：分享与海报功能** | 第11周 | 生成二维码分享卡片 | 可导出图片+二维码链接 |
| **W12：测试与发布** | 第12周 | 功能测试、性能优化 | MVP内测版上线 |

> 🚀 **MVP上线目标**：实现“孩子输入想象 → AI生成 → 涂色 → 成长记录上链 → 可分享”。

## 🌈 三、用户群体与角色定位

| 用户类型 | 角色定位 | 行为特征 |
|------------|-----------|------------|
| 👧 儿童（5–10岁） | 创造者 | 喜欢画画、讲故事、模仿动画形象；好奇心强、视觉驱动；不喜欢枯燥背单词。 |
| 👩 家长 | 记录者 & 引导者 | 希望看到孩子成长、有趣的学习成果、可分享的内容。 |
| 🧑 教师（后期扩展） | 引导者 | 可用于课堂启发想象或语言创作。 |

> MVP 阶段聚焦“孩子 + 家长共学”，教师角色暂不开放。

## 🧩 四、产品核心理念：AI + 想象 + 表达 + 记录

```mermaid
graph TD
A[孩子的想象] --> B[AI生成图像]
B --> C[孩子二次创作(涂色/绘画)]
C --> D[AI辅助生成英语短句]
D --> E[生成想象卡(图片+语言+二维码)]
E --> F[区块链确权成长记录]
F --> G[家长查看/分享]
```

**核心教育逻辑**：
1. 孩子通过“想象”激活创造力；
2. AI帮助他们可视化思维；
3. 绘画与语言表达结合，形成立体认知；
4. 区块链记录每一步成长的“作品确权”。

## 🧠 五、核心功能模块

| 模块 | 功能描述 | 关键输出 | 技术依赖 | 时间节点 |
|--------|-------------|-----------|------------|------------|
| 🧒 想象生成 | 孩子输入主题（语音/文字） | 想象主题文本 | Dify + GPT | W3–W4 |
| 🎨 图像创造 | 根据主题生成卡通风格图片 | 图像URL | Dify + SDXL / FLUX | W3–W4 |
| ✏️ 涂色创作 | 将AI图片转为线稿，孩子可上色 | PNG作品 | Flutter CanvasKit | W5–W6 |
| 🗣️ 英语表达 | 根据主题与图像自动生成1–2句英文 | 英语短句 + 语音 | GPT + FlutterTTS | W5–W6 |
| 🗣️ 跟读与语音反馈（MVP） | 孩子对生成的英文进行录音 → 系统识别并给出简单反馈（👍/再试/没听清） | 跟读结果JSON（目标句、识别文本、评分等级） | Flutter录音 + Rust ASR对比 + 简单评分规则 | W6–W7 |
| 💾 成长记录 | 保存孩子作品 + 生成哈希 | 作品JSON + Hash | Rust + PostgreSQL + S3 | W7–W8 |
| 🔗 区块链确权 | 将作品哈希上链（Substrate） | 链上Tx哈希 | Rust + Polkadot SDK | W9–W10 |
| 📤 分享传播 | 生成作品海报 + 二维码链接 | 图片 + 短链 | Rust image crate + qrcode | W11 | |

## 🧭 六、产品体验路径

**孩子体验**：输入想象 → AI生成 → 涂色 → 听英文 → 保存作品。  
**家长体验**：查看作品 → 生成海报 → 分享朋友圈 → 链上确权。

## ✅ 八、结语

> **Kiki漫游** 是一个融合艺术、语言与科技的儿童创造力生态。  
> 它的使命不是教会孩子知识，而是 **唤醒他们创造世界的能力**。  
> 每一次想象，都是一次探索；每一幅画，都是孩子灵魂的印记；  
> 而区块链，让这些创造“永不消失”。

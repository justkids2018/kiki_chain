# 场景预设：scene_03_日常生活

本文件定义日常生活类学习卡片的场景背景规则。

## 场景目标

- 画面应表达儿童熟悉的真实生活空间，例如超市、公园、生日派对、浴室、衣柜、诊所。
- 场景位置必须自然可信，但视觉表现仍然遵守玩具微缩场景风格。
- 目标物体应放在真实使用位置，而不是全部集中在展示台。

## 背景分层

- 前景：放置 2-3 个最大、最清晰、最容易点击的目标物体。
- 中景：放置主要人物动作、核心生活行为和 3-4 个目标物体。
- 后景：放置空间锚点、家具、墙面、窗户、货架或背景物体，但不得抢主目标。

## 氛围

- 生活化、自然、熟悉、干净。
- 光照温暖舒适，适合 3-6 岁儿童学习。
- 背景可以丰富，但不得造成目标物体识别困难。

## 易错防护

- 小物体必须放大到可识别。
- 相似物体必须分开放置，并用不同箭头方向区分。
- 日常空间里的大量背景杂物不得被误当作目标物体。

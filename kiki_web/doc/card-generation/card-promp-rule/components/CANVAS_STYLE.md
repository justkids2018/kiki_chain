# 画布与整体风格组件规范

本文件只定义图片生成的画布、视角、材质和总体风格优先级。

## 最高优先级风格锁

- 整体必须是 `premium miniature toy diorama`，像高质感儿童学习玩具微缩场景。
- 必须是 `Indoor Montessori learning room style`。
- 物体必须是圆润、饱满、柔和 3D 体积，带清晰接触阴影和柔和高光。
- 材质应像精致儿童教具、木质玩具、软塑玩具、布艺软垫和温暖室内材料。
- 画面可以表达真实生活位置，但不能生成真实摄影、商场监控照、真人写实照片或普通超市货架照片。
- 当 `real scene` 与 `toy diorama` 发生冲突时，`toy diorama` 优先。

## 画布硬约束

- 画面必须是正方形构图，目标输出为 1024x1024。
- 必须完整使用整个正方形画布。
- 禁止竖版裁切、横版裁切、内框、外框、大面积空白边。
- 视角固定为略俯视的 3/4 top-front view。
- 场景必须有前景、中景、后景层次。

## 视觉方向

- 整体像 Apple 级儿童教育产品广告里的微缩玩具场景。
- 场景应温暖、清晰、干净、可触摸。
- 主体中心更清晰，远处和边缘允许轻微柔化，但目标物体必须可识别。
- 保持真实比例关系，但允许将小物件适度放大，保证儿童可识别和后续热区可框选。

## 禁止项

- 禁止真实摄影风格。
- 禁止普通超市/公园/医院现场照片感。
- 禁止真人照片质感。
- 禁止平面插画、纸片拼贴、海报式大标题。
- 禁止把所有目标物体堆在展示台上，除非当前主题本身就是展示台。

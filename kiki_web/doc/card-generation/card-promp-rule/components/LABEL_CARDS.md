# 标签卡片组件规范

这个文件只定义标签卡片本体，不定义场景背景或目标词内容。

## 必须规则

- 所有标签卡片必须使用同一套组件样式
- 卡片必须是圆角矩形
- 卡片必须带轻微 3D 厚度
- 卡片必须有柔和高光和轻微浮动阴影
- 卡片必须保持紧凑，不遮挡主体物体
- 卡片底色必须使用暖白色或柔和白色
- 卡片外层必须有一条非常细的边框线
- 边框必须低对比、轻、干净，不能发黑发重
- 所有卡片必须保持一致的圆角、厚度、边框、内边距和阴影语言

## 推荐方向

- 卡片感觉应接近小型立体贴纸牌或小型说明牌
- 卡片不要做成纯平面打印纸片
- 卡片不要过厚、过重、过玩具化
- 边框颜色可偏浅暖灰、浅米灰、或非常淡的灰蓝色

## 禁止项

- 禁止高反差纯白卡片
- 禁止厚重黑边框
- 禁止卡片尺寸过大压住物体主体
- 禁止同一张图里出现多套不同卡片样式

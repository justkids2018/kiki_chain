## 改版核心

- **一级分类**：春节场景、24节气、日常生活、游乐场景等

## 数据结构

### 一级分类（SceneCategory）
```dart
class SceneCategory {
  String id;                    // 分类ID
  String name;                  // 分类名（如"春节场景"）
  String coverImage;            // 分类封面图
  String icon;                  // 分类图标emoji
  int sceneCount;               // 子场景数量
  int totalItemCount;           // 该分类下所有物品总数
  DateTime createdAt;           // 创建时间
}
```

### 二级场景（Scene）
```dart
class Scene {
  String id;                    // 场景ID
  String categoryId;            // 所属分类ID
  String name;                  // 场景名（如"除夕"）
  String coverImage;            // 场景封面图
  String interactiveImageUrl;   // 互动大图URL
  String interactiveJsonUrl;    // 热区JSON配置URL
  int itemCount;                // 物品数量
  int learnedItemCount;         // 已学习物品数（登录用户）
  DateTime createdAt;           // 创建时间
}
```

### 学习记录（LearningRecord）
```dart
class LearningRecord {
  String userId;                // 用户ID
  String sceneId;               // 场景ID（二级场景）
  int learnedItemCount;         // 已学习物品数
  int totalItemCount;           // 总物品数
  Duration studyTime;           // 学习时长
  DateTime lastStudyAt;         // 最后学习时间

  // 计算属性
  double get progress => learnedItemCount / totalItemCount;
  int get starCount => progress >= 0.9 ? 3 : (progress >= 0.6 ? 2 : (progress >= 0.3 ? 1 : 0));
}
```

## 导航流程

```
主页（一级分类列表）
    ↓ 点击"春节场景"卡片
二级场景列表（春节下的5个场景）
    ↓ 点击"除夕"卡片
学习详情页（互动图片页）
    ↓ 点击热区学习物品
学习内容展示（汉字笔顺+英文+语音）
```

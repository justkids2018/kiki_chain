## 一、技术架构概述

### 1.1 整体架构

Kiki World 采用 **Clean Architecture（清洁架构）** 分层设计，确保代码的可维护性、可测试性和可扩展性。

### 1.2 架构原则

- **依赖倒置**：高层模块不依赖低层模块，都依赖于抽象
- **单一职责**：每层只负责特定的功能
- **关注点分离**：UI、业务逻辑、数据层分离
- **可测试性**：各层独立，易于单元测试

## 三、核心技术栈

### 3.1 状态管理：GetX

**版本**：^4.6.5

**选择理由**：
- 轻量级，性能优秀
- 响应式编程简单
- 内置路由管理
- 依赖注入便捷

**核心用法**：

```dart
// 1. 控制器定义
class InteractiveImageController extends GetxController {
  final selectedRegion = Rx<InteractiveRegion?>(null);

  void selectRegion(InteractiveRegion region) {
    selectedRegion.value = region;
  }
}

// 2. 依赖注入
Get.put(InteractiveImageController());

// 3. UI响应式更新
Obx(() => Text(controller.selectedRegion.value?.text ?? ''))
```

**关键API**：
- `Get.put()` / `Get.find()`: 依赖注入
- `.obs`: 响应式变量
- `Obx()` / `GetBuilder()`: UI更新
- `Get.toNamed()` / `Get.back()`: 路由导航

### 3.2 网络层：Dio

**版本**：^5.3.0

**拦截器链**：

```
请求 → AuthInterceptor（添加Token）
    → NetworkStatusInterceptor（检查网络）
    → CacheInterceptor（缓存管理）
    → LoggingInterceptor（日志记录）
    → 发送请求
    ↓
响应 ← RetryInterceptor（失败重试）
    ← CacheInterceptor（缓存存储）
    ← LoggingInterceptor（日志记录）
    ← 返回数据
```

**配置示例**：

```dart
// lib/core/network/dio_client.dart
final dio = Dio(BaseOptions(
  baseUrl: EnvConfig.apiBaseUrl,
  connectTimeout: Duration(milliseconds: 30000),
  receiveTimeout: Duration(milliseconds: 30000),
));

dio.interceptors.addAll([
  AuthInterceptor(),
  NetworkStatusInterceptor(),
  CacheInterceptor(),
  RetryInterceptor(),
  LoggingInterceptor(),
]);
```

**关键文件**：
- `lib/core/network/dio_client.dart`
- `lib/core/network/interceptors/auth_interceptor.dart`
- `lib/core/network/interceptors/retry_interceptor.dart`

```dart
void _displayCharacterStrokes(String text) {
  characterCells.value = text.characters.map((char) =>
    CharacterCell(character: char, status: CharacterCellStatus.pending)
  ).toList();

  // 逐个解锁
  _unlockNextCharacter();
}

void _unlockNextCharacter() {
  final index = characterCells.indexWhere(
    (cell) => cell.status == CharacterCellStatus.pending
  );
  if (index != -1) {
    characterCells[index].status = CharacterCellStatus.active;
  }
}
```

```dart
class LanguageController extends GetxController {
  final _storage = Get.find<LocalStorageService>();
  final locale = const Locale('zh', 'CN').obs;

  @override
  void onInit() {
    super.onInit();
    _loadSavedLanguage();
  }

  // 加载保存的语言
  Future<void> _loadSavedLanguage() async {
    final savedLang = await _storage.getString('language');
    if (savedLang != null) {
      locale.value = _getLocaleFromString(savedLang);
    }
  }

  // 切换语言
  Future<void> changeLanguage(String langCode) async {
    locale.value = _getLocaleFromString(langCode);
    await _storage.setString('language', langCode);
    Get.updateLocale(locale.value);
  }
}
```

```dart
class EnvConfig {
  static String apiBaseUrl = '';
  static String envType = '';
  static bool debug = true;
  static bool enableLogging = true;

  static Future<void> load() async {
    final env = const String.fromEnvironment('APP_ENV', defaultValue: 'dev');
    final envFile = 'environments/$env.env';

    final envString = await rootBundle.loadString(envFile);
    final envMap = _parseEnv(envString);

    apiBaseUrl = envMap['API_BASE_URL'] ?? '';
    envType = envMap['ENV_TYPE'] ?? 'dev';
    debug = envMap['DEBUG'] == 'true';
    enableLogging = envMap['ENABLE_LOGGING'] == 'true';
  }
}
```

## 十一、性能优化

### 11.1 图片优化
- 使用合适的图片格式（JPG用于照片，PNG用于透明图）
- 压缩图片大小（植物园图片：712KB，可优化至300KB以下）
- 使用`CachedNetworkImage`缓存远程图片

### 11.2 动画优化
- 使用`RepaintBoundary`隔离重绘区域
- 汉字笔顺动画使用`CustomPaint`减少Widget层级
- 气泡动画使用`AnimatedBuilder`优化性能

### 11.3 内存优化
- 及时释放Controller（`onClose()`中清理资源）
- TTS服务在页面销毁时停止
- 图片缓存策略（LRU缓存，最大100MB）

### 11.4 网络优化
- 使用Dio缓存拦截器
- 请求失败自动重试（最多3次）
- 并发请求限制（最多5个）

## 十四、技术债务与改进方向

### 14.1 当前技术债务
1. **缺少完整的错误处理机制**
   - 网络请求失败时用户体验不佳
   - 需要统一的错误处理中间件

2. **测试覆盖率不足**
   - 缺少完整的单元测试
   - 缺少集成测试

3. **代码重复**
   - 多个页面有相似的加载逻辑
   - 可抽取通用BaseController

4. **性能监控缺失**
   - 缺少性能埋点
   - 无法追踪线上性能问题

### 14.2 改进方向

#### 短期改进（1-3个月）
- 补充单元测试和Widget测试
- 统一错误处理机制
- 优化图片资源（压缩 + WebP格式）
- 添加性能监控（Firebase Performance）

#### 中期改进（3-6个月）
- 引入状态管理优化（Riverpod替代GetX）
- 模块化拆分（Feature-based架构）
- CI/CD自动化（GitHub Actions）
- 代码质量检查（SonarQube）

#### 长期改进（6-12个月）
- 微前端架构（Flutter Web支持）
- 离线优先策略（Offline-first）
- 国际化增强（支持更多语言）
- 无障碍访问（Accessibility）

# 汉字描红练习页需求

## 目的

在当前学习卡片页提供一个练写入口，让学生把卡片中的汉字转换为可描红、可打印的练习纸。

## 范围

1. 在学习卡片页增加练写入口。
2. 新增练字页面，读取当前卡片的学习词条。
3. 练习纸每行默认 10 个田字格，词语连续铺排；词语之间间隔 1 格，不够放下整个词则换行。
4. 页面提供练习纸预览，不提供手指或鼠标画线能力。
5. 支持生成 A4 PDF 并调用移动端系统打印面板。

## 非范围

1. 不新增后端接口。
2. 不改现有卡片 JSON 数据结构。
3. 不在第一版保存学生描写轨迹。
4. 不做 Web 专用打印路径，本项目按移动端能力实现。

## 验收

1. 学习卡片页能打开练字页。
2. 练字页展示当前卡片全部学习汉字。
3. 每个词语块上方显示每字拼音和黑色正楷示范字，下方显示同宽浅红描红字给孩子练习；行尾不足 10 格时补空白格。
4. 田字格不产生手绘笔画或横道。
5. 点击打印能调起系统打印流程。
6. PDF 默认展示 Hi Kiki 图标。
7. PDF 练习纸空白区域仅在左上角和右下角展示 `Hi Kiki` 标签。

# Code Generator - 通用代码生成规范

> **适用范围**: 所有多端架构项目
> **版本**: v1.0

---

## 📋 核心原则

### 1. 模板驱动（Template-Driven）

所有代码通过模板生成，确保一致性和可维护性。

### 2. 80/20 原则

- 生成 80% 的框架代码
- 留 20% 让开发者补充业务逻辑

### 3. 类型安全（Type Safety）

确保生成的代码类型正确，编译通过。

---

## ✅ 最佳实践

### 模板组织
- 按语言分类（rust/, dart/, sql/）
- 使用 Handlebars 语法
- 提供清晰的变量说明

### 代码质量
- 生成的代码必须符合项目规范
- 包含必要的注释
- 使用 TODO 标记需要补充的部分

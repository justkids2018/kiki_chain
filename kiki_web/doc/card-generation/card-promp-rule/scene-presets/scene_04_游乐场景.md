# 场景预设：scene_04_游乐场景

本文件定义游乐场景类学习卡片的场景背景规则。

## 场景目标

- 画面应表达儿童熟悉、开心、可探索的想象游乐空间，例如恐龙世界、太空探险、海盗船、童话城堡、马戏团、沙滩乐园。
- 场景可以更有想象力，但视觉表现仍然遵守高质感玩具微缩场景风格。
- 所有目标物体必须清晰、可识别、可框选，不能被奇幻氛围吞掉。

## 背景分层

- 前景：放置 2-3 个最大、最清晰、最容易点击的目标物体。
- 中景：放置主要人物动作、核心游乐行为和 3-4 个目标物体。
- 后景：放置主题空间锚点，例如火山、城堡、船体、帐篷、月球、海面或天空元素。

## 氛围

- 快乐、积极、冒险、明亮、童趣。
- 可以有梦幻光影，但不能压暗人物、标签或目标物体。
- 奇幻元素必须服务主题，不得变成无关装饰。

## 易错防护

- 想象类大背景物体必须和目标物体明确区分。
- 同类小物体必须分开放大，避免模型把它们画成一片纹理。
- 天空、海面、城堡、船体等背景区域不能抢走标签箭头落点。

# 场景预设：scene_02_数学思维

本文件定义数学思维类学习卡片的场景背景规则。

## 场景目标

- 画面应表达 3-6 岁儿童**通过具象物品建立数学认知**的学习空间，例如数数、配对、形状、比大小、找规律、空间关系。
- 场景必须让数学概念**通过可数、可分组、可比对的实物**自然呈现，不允许仅靠抽象符号承担。
- 视觉表现仍然遵守玩具微缩场景风格：圆润、明亮、可触摸感。

## 背景分层

- 前景：放置 2-3 组最大、最清晰、最容易点击的目标物体集合（如 3 个红苹果、2 个黄香蕉），间距明显方便点数。
- 中景：放置主要人物动作（数数、配对、摆放）和 3-4 个目标物体集合。
- 后景：放置空间锚点（教室白板、数字地毯、积木墙、形状收纳柜），但不得抢主目标。

## 氛围

- 干净、明亮、清晰、低饱和度对比、几何感强。
- 主色调建议：奶白、天蓝、薄荷绿、鹅黄、柔粉。
- 光照均匀明亮，避免戏剧化阴影遮挡数量识别。
- 严禁过度繁杂的装饰，保持可识别性。

## 物品分布原则

- 每张卡的 8 个词条建议构成：
  - **可计数物品组**（苹果、积木、铅笔、玩偶、数字卡片）
  - **形状物品**（圆球、立方体、三角积木、星星贴纸）
  - **配对物品**（袜子对、手套对、鞋子对、对应玩具）
- 同一张卡的 8 个词条**必须围绕一个数学主题**（"数数到 8""比形状""找一对"），不允许跨主题混搭。
- 词条本身仍是**具体物品名词**（苹果、积木、星星），不允许把"加法""减法""更多""更少"作为标签词条。

## 易错防护

- 数量必须**在画面中真实可数**：标签写"3 个苹果"，画面就必须有 3 个清晰可见、不互相遮挡的苹果。
- 形状物品的形状特征必须立得住：立方体不能被画成长方体，三角形不能被画成不规则四边形。
- 不允许同时出现两个**视觉极易混淆**的形状（圆球 / 圆盘、立方体 / 长方体）。
- 不允许把数字符号（"3""5""8"）当作目标词条，数字仅可作为辅助贴纸出现在背景。
- 数学卡可适度让姐妹做"数数 / 摆放 / 比较"动作，但**不得替换姐妹+小白猫的固定人设**。

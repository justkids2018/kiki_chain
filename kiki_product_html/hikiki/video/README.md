# Hi Kiki Video Kit

目标：用现有图片和文案，低成本生成“可录制”的故事视频页。

## 目录

- `index.html`：视频故事播放页（通用引擎 + 项目配置）

## 快速使用

1. 修改 `index.html` 顶部 `VIDEO_CONFIG`：
- `title`：视频标题
- `subtitle`：副标题
- `scenes`：镜头列表（图片、文案、时长）
- `narration`：双人声台词（可空）

2. 准备素材：
- 推荐图尺寸：1080x1920（竖屏）或 1920x1080（横屏）
- 临时可先复用 `../img/` 下截图

3. 本地打开页面预览：
- 直接浏览器打开 `video/index.html`

4. 导出视频（省钱方案）：
- 用系统录屏或 OBS 录制页面播放
- 导入 CapCut/剪映补字幕和背景音乐后导出 MP4

## 成本建议

- 基础版（最低成本）：仅 HTML 动效 + TTS 配音 + 录屏导出
- 增强版（可选）：只在开头 3 秒加入一段图生视频镜头，不要全片依赖

## 推荐长度

- 首发短视频：30-45 秒
- 镜头数：5-8
- 单镜头时长：3-6 秒

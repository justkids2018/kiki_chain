## 2. 核心接口详情

### 2.1 用户登录

调用时机：用户在身份入口提交账号信息。  
所属区块：启动与身份入口。

请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 请求体 | 手机号 | 字符串 | 是 | 用户登录账号 |
| 请求体 | 密码 | 字符串 | 是 | 用户身份校验凭据 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 操作结果 | 布尔值 | 登录是否成功 |
| 登录凭证 | 字符串 | 后续身份认证所需凭证 |
| 用户信息 | 对象 | 当前登录用户的基础资料 |
| 提示信息 | 字符串 | 登录结果说明 |

错误情况：

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 400 | 输入不符合要求 | 修正输入后重试 |
| 401 | 账号或密码不正确 | 无法登录 |
| 500 | 服务异常 | 稍后重试 |

### 2.2 获取主题下学习卡片

调用时机：儿童点击一个学习主题。  
所属区块：主题学习卡片列表。

请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 路径 | 主题标识 | 整数 | 是 | 要浏览的主题 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 操作结果 | 布尔值 | 请求是否成功 |
| 学习卡片列表 | 数组 | 主题下可展示的卡片 |
| 卡片标识 | 整数 | 学习卡片唯一标识 |
| 卡片名称 | 字符串 | 面向用户展示的名称 |
| 卡片封面 | 字符串 | 卡片封面资源地址 |
| 展示顺序 | 整数 | 卡片在主题内的排序 |
| 可用状态 | 布尔值 | 当前是否允许展示或学习 |
| 分页信息 | 对象 | 当前页、每页数量和总量 |

错误情况：

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 404 | 主题不存在 | 无法查看该主题 |
| 500 | 内容服务异常 | 列表暂时不可用 |

### 2.3 获取学习卡片详情

调用时机：儿童打开一张学习卡片。  
所属区块：互动场景学习。

请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 路径 | 卡片标识 | 整数 | 是 | 要学习的卡片 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 卡片信息 | 对象 | 卡片名称、说明和展示配置 |
| 场景图片 | 字符串 | 互动学习主图资源地址 |
| 词条列表 | 数组 | 场景内所有学习目标 |
| 中文词语 | 字符串 | 目标的中文学习文本 |
| 英文词语 | 字符串 | 目标的英文学习文本 |
| 中文音频 | 字符串 | 中文发音资源地址 |
| 英文音频 | 字符串 | 英文发音资源地址 |
| 点击区域 | 对象 | 目标在场景图中的可交互范围 |
| 展示顺序 | 整数 | 词条引导顺序 |

错误情况：

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 401 | 用户身份无效 | 需要重新登录 |
| 403 | 当前权益不足 | 引导查看会员权益 |
| 404 | 卡片不存在或不可用 | 无法进入学习 |
| 500 | 服务异常 | 可返回并重试 |

### 2.4 批量保存学习进度

调用时机：儿童结束或阶段性完成学习。  
所属区块：互动场景学习。

请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 请求体 | 用户标识 | 整数 | 是 | 学习者身份 |
| 请求体 | 进度列表 | 数组 | 是 | 本次需要保存的一组学习结果 |
| 请求体 | 卡片标识 | 整数 | 是 | 对应学习卡片 |
| 请求体 | 完成程度 | 数值 | 是 | 当前学习完成情况 |
| 请求体 | 学习状态 | 字符串 | 是 | 未开始、学习中或已完成等业务状态 |
| 请求体 | 最近学习时间 | 时间 | 否 | 本次学习发生时间 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 操作结果 | 布尔值 | 是否保存成功 |
| 成功数量 | 整数 | 成功写入的记录数 |
| 失败项目 | 数组 | 未成功项目及原因 |
| 最新进度 | 数组 | 保存后的有效学习状态 |

错误情况：

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 400 | 进度内容不合法 | 当前结果需重新计算或放弃同步 |
| 401 | 身份失效 | 重新登录后同步 |
| 500 | 保存失败 | 保留待同步状态并重试 |

### 2.5 获取学习汇总

调用时机：用户打开成长与学习记录页。  
所属区块：成长与学习记录。

请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 路径 | 用户标识 | 整数 | 是 | 要查看的学习者 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 学习卡片总数 | 整数 | 参与过学习的卡片数量 |
| 已完成数量 | 整数 | 达到完成标准的卡片数量 |
| 总体完成率 | 数值 | 学习完成比例 |
| 最近学习时间 | 时间 | 最近一次有效学习时间 |
| 主题汇总 | 数组 | 按主题聚合的学习结果 |

错误情况：

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 401 | 未获得访问权限 | 无法查看成长信息 |
| 404 | 用户不存在 | 无可展示数据 |
| 500 | 汇总失败 | 稍后重试 |

### 2.6 创建与确认订阅订单

调用时机：用户选择订阅产品并完成外部支付流程。  
所属区块：VIP 订阅。

创建订单请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 请求体 | 产品标识 | 字符串 | 是 | 用户选择的订阅产品 |
| 请求体 | 地区 | 字符串 | 是 | 产品与支付适用地区 |
| 请求体 | 设备平台 | 字符串 | 是 | 当前运行平台 |
| 请求体 | 分发渠道 | 字符串 | 是 | App 获取来源 |
| 请求体 | 支付渠道 | 字符串 | 是 | 实际使用的支付方式 |

确认订单请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 路径 | 订单标识 | 字符串 | 是 | 待确认订单 |
| 请求体 | 支付凭证 | 字符串 | 是 | 验证支付结果所需凭据 |
| 请求体 | 渠道交易标识 | 字符串 | 否 | 支付渠道返回的交易标识 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 订单标识 | 字符串 | 当前订单唯一标识 |
| 订单状态 | 字符串 | 待支付、确认中、成功、失败或取消 |
| 权益状态 | 对象 | 生效后的会员等级与有效期 |
| 是否重复确认 | 布尔值 | 本次是否返回既有确认结果 |

错误情况：

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 400 | 产品、渠道或凭证不合法 | 无法完成购买 |
| 401 | 登录状态失效 | 重新登录后处理 |
| 409 | 订单状态不允许当前操作 | 刷新订单结果 |
| 500 | 确认服务异常 | 保留订单并允许安全重试 |

### 2.7 管理后台维护学习卡片

调用时机：运营人员创建或保存学习卡片。  
所属区块：学习卡片管理。

请求参数：

| 参数位置 | 参数名 | 类型 | 必填 | 业务含义 |
|---|---|---|---|---|
| 路径 | 卡片标识 | 整数 | 更新时必填 | 要修改的学习卡片 |
| 请求体 | 所属主题 | 整数 | 是 | 卡片归属主题 |
| 请求体 | 卡片名称 | 字符串 | 是 | 面向用户展示的名称 |
| 请求体 | 场景图片 | 字符串 | 是 | 互动学习主图地址 |
| 请求体 | 卡片说明 | 字符串 | 否 | 内容介绍或运营备注 |
| 请求体 | 展示顺序 | 整数 | 是 | 主题内排序 |
| 请求体 | 可用状态 | 布尔值 | 是 | 是否允许移动端读取 |
| 请求体 | 词条列表 | 数组 | 是 | 中英文词条、音频和热区集合 |

响应字段：

| 字段名 | 类型 | 业务含义 |
|---|---|---|
| 操作结果 | 布尔值 | 是否保存成功 |
| 卡片信息 | 对象 | 保存后的完整业务内容 |
| 校验问题 | 数组 | 未通过的内容完整性问题 |

| 状态码 | 说明 | 用户影响 |
|---|---|---|
| 400 | 内容或热区校验失败 | 修正后重新提交 |
| 401 | 管理员登录失效 | 重新登录 |
| 403 | 无内容维护权限 | 无法保存 |
| 404 | 主题或卡片不存在 | 返回列表核对 |
| 409 | 内容版本冲突 | 刷新后重新编辑 |

## 3. 通用约定

- 除公开登录、注册和健康检查外，接口应携带有效身份凭证。
- 成功响应包含操作结果、业务数据和提示信息；失败响应包含错误标识与可理解的说明。
- 列表接口在数据量可能增长时应提供分页信息。
- 时间统一使用带时区的标准格式，客户端负责本地展示。
- 写入接口应支持防重复提交；学习进度和订阅确认必须具备幂等语义。
- 管理后台接口与移动端接口应保持权限和地址空间隔离。

## 5. 契约一致性提示

本项目共享接口文档中仍可见历史接口口径，而当前后端已形成移动端场景、学习记录、订阅、用户与反馈等新路径。本文优先描述已形成主业务链的接口，但在下一次接口变更前，仍建议逐项核对后端实际路由、移动端调用和共享接口文档，消除路径与字段差异。

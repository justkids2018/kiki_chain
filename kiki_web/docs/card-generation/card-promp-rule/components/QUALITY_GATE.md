# 生成前质检组件规范

本文件定义每张学习卡片图片生成前必须执行的自检。

## 必须通过的 6 个检查

1. DIRTY TEXT SCAN：每张标签卡片必须只有三行 `[pinyin] / hanzi / english`，不得出现引用、序号、占位符或额外文本。
2. CLOSED VOCAB SCAN：每张标签卡片必须来自当前 md 的 `### III` 词表行；不得出现词表外标签、近义词替换、同类物替换或额外学习对象。
3. COUNT CHECK：目标物体数、标签卡片数、箭头数必须与当前 md 词表数量 `N` 完全一致；禁止默认按 8 个处理。
4. MAPPING CHECK：每个标签卡片必须对应正确目标物体，不得错配、重复或漏标。
5. ARROW PRECISION：每根箭头必须触碰目标物体本体，不得悬空、指背景、交叉或指向相邻物体。
6. VISUAL CHECK：场景必须符合画布、风格、层次、识别度和品牌角标要求。

## 失败处理

- 任一检查失败，必须重新生成布局。
- 不允许把失败项留给后续 JSON 解析修复。
- 不允许因为整体画面好看而忽略对象错配、文字污染或箭头落点问题。
- 不允许因为场景更自然而替换 md 词条；词表准确性优先于场景丰富度。

## 热区友好要求

- 每个目标物体必须有清晰边界，适合后续框选 `object` 区域。
- 每张标签卡片必须有完整矩形边界，适合后续框选 `card` 区域。
- 标签卡片不能覆盖目标物体主体。
- 目标物体之间不能重叠到无法判断语义归属。
- 若有 1-2 个对象或箭头映射不确定，图片不进入 JSON 阶段；必须先重生或人工修正图片。

# 场景预设：scene_05_中国节日

本文件定义中国节日类学习卡片的场景背景规则。

## 场景目标

- 画面应表达温暖、喜庆、富有中国节日氛围的家庭/庭院/校园空间，例如端午包粽、中秋赏月、冬至吃饺子、春节贴春联、元宵赏花灯。
- 场景必须**保留传统节日的视觉符号**（节日食物、典型挂饰、特定活动道具），让 3-6 岁孩子第一眼就能识别节日。
- 视觉表现仍然遵守玩具微缩场景风格：圆润、温暖、可触摸感，不是真实摄影。

## 背景分层

- 前景：放置 2-3 个最大、最清晰、最容易点击的目标物体（通常是节日食物或核心标志物）。
- 中景：放置主要人物动作和 3-4 个目标物体（节日活动道具，如香包、灯笼、风筝）。
- 后景：放置节日空间锚点（春联、福字墙、月亮窗景、年画屏风、节日窗花），但不得抢主目标。

## 氛围

- 温暖、喜庆、安宁、有仪式感、家庭感强烈。
- 主色调建议：
  - 春节 / 元宵：中国红、暖金、米白
  - 端午：竹叶绿、雄黄黄、艾草青
  - 中秋：暖月白、桂花橙、夜空靛蓝（保持明亮可识别）
  - 重阳：菊花金黄、登山棕、秋叶橙
  - 冬至：暖灰白、雪青、姜黄（饺子皮色）
- 光照温暖偏暖色，让节日氛围自然流露，但要保证目标物体的颜色和材质清晰。
- 不允许过度黑暗、烟雾过浓、鞭炮爆炸特效压过画面。

## 物品分布原则

- 每张卡的 8 个词条建议组合：
  - **2-3 个食物**：节日特色吃食（粽子、月饼、饺子、汤圆、糖葫芦）
  - **2-3 个标志物**：节日典型物品（灯笼、福字、对联、月亮、菊花、艾草）
  - **1-2 个活动道具**：互动物（红包、香包、五彩绳、风筝、花灯）
  - **0-1 个角色 / 装饰**：节日相关角色或形象（嫦娥像、玉兔玩偶、舞狮玩偶、年画娃娃）
- 严禁把抽象概念（"团圆""孝顺""祝福"）作为目标词条。

## 易错防护

- 节日食物之间必须有清晰区分：粽子（绿叶包扎三角形）、月饼（圆形带花纹）、饺子（白色月牙形）、汤圆（白色光滑圆球）不能渲染成类似形状。
- 灯笼、花灯、宫灯需要保留各自典型形态：灯笼 = 红色圆形竖挂；花灯 = 兔子/鱼/莲花造型彩灯；宫灯 = 多面形带流苏。
- 对联、福字、年画必须保留汉字可读性（哪怕只是装饰性的"福"字），不允许写成乱码或英文。
- 月亮、灯笼、纸鸢等悬挂或飘浮物体必须放在合理位置（天上、屋檐下），不得随意悬空。
- 节日服装可以让姐妹穿应景的传统元素（盘扣外套、改良汉服、节日围裙），但**不得替换姐妹+小白猫的固定人设**。

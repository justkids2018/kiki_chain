# Kiki 管理后台 UI 升级代码审查

## 结论

`APPROVED_WITH_CONCERNS`

## 阻断问题

无。

## 审查证据

- 视觉变量通过 `.kiki-admin` 限定 Element Plus 覆盖，降低旧页面样式污染。
- `Layout.vue` 保留路由、退出与缓存逻辑，只调整表现层和侧栏状态。
- `Users.vue` 保留列表、搜索、详情、编辑和更新 API 行为。
- `Login.vue` 保留表单校验、管理员角色判断、Token 存储和登录跳转。
- 图片 CDN 当前域名与历史域名识别集中在 `image-cdn.ts`，旧 URL 只迁移主机名，路径、查询参数和哈希保持不变。
- 未修改 API、数据库、权限模型和发布链路。

## 关注项

- 后台登录后多宽度动态截图尚未补齐，需要有效管理员账号。
- 生产 Nginx 的 `/cdn/` 已指向新域名，旧 `/cdn-legacy/` 可在后续确认无调用后单独清理，本次不破坏发布兼容路径。
- Element Plus 主分块仍超过默认提示阈值，属于既有问题。

## 回滚

- UI commit 可独立回滚，恢复原布局和页面样式。
- CDN commit 可独立回滚，恢复旧域名本地代理。

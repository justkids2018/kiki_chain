# 数字认知场景 - 分类卡片封面图生成 Prompt（RULES 对齐版）

---

## 📋 基础规格

- 用途: 一级场景分类卡片封面图
- 场景分类: 数字认知 (Number Recognition Scenes)
- 输出格式: PNG
- 画幅: 7:9 竖版
- 推荐分辨率: 700 x 900 (@2x)
- 可选分辨率: 350 x 450 (@1x), 1050 x 1350 (@3x)
- 色深: 24-bit RGB
- 适用年龄: 3-6 岁

---

## 🔒 借鉴 RULES.md 的硬约束（封面版）

- 必须是完整数字学习场景，不是数字贴纸陈列。
- 必须具备前景 / 中景 / 后景分层。
- 必须固定出现 2 个可爱小女孩（10 岁姐姐 + 4 岁双马尾妹妹）。
- 必须固定出现 1 只可爱白色小猫。
- 三个角色必须分布在不同景深层。
- 禁止大标题文字、引用标记、脚注标记。
- 禁止画面内框和留白。

---

## 🎨 完整生成 Prompt

```text
Create a premium 3D rendered category cover for "Number Recognition Scenes" for children aged 3-6.

Output:
- PNG, portrait 7:9
- Preferred 700x900 px (@2x)
- Full canvas usage

Scene goal:
Build a complete number-learning play environment with clear educational cues (large friendly numerals, counting toys, blocks, dots), not a flat infographic board.

Mandatory character baseline:
- Exactly two cute sister girls: one 10-year-old older sister and one 4-year-old younger sister with two ponytails
- Exactly one cute white kitten
- Place each in different depth layers (foreground / midground / background)

Depth and composition:
- Foreground: one prominent numeral-related object (counting beads or big number block)
- Midground: core number activity zone with strongest readability
- Background: simplified classroom or learning-wall anchors
- Keep visual rhythm clean and educational

Visual direction:
- Fresh educational palette (mint, sky blue, lemon yellow, soft orange)
- Rounded, tactile 3D teaching-toy style
- Crisp center focus, subtly softened far background
- Warm, reassuring classroom light

Prohibitions:
- No giant text title
- No [cite:x], [ref:x], [source:x], superscripts, or extra markers
- No replacing required sister+kitten baseline
- No dense clutter that harms number readability

Quality target:
Clear, friendly, educational number category cover.
```

# 品牌角标组件规范

这个文件只定义右上角的 Hi Kiki 品牌角标。

## 必须规则

- 只允许一行文字：`Hi Kiki`
- 角标必须固定在右上角
- 角标必须贴边，不能漂浮在角落内侧
- 角标必须使用固定组件样式，不可每张图变化
- 角标底牌必须为暖白或柔和白的圆角 3D 卡片
- 角标需要轻微厚度、柔和阴影和极细边框
- 品牌文字必须使用固定的柔和天蓝色
- 不允许白色品牌文字

## 视觉方向

- 整体应小巧、安静、低视觉权重
- 看起来像贴在右上边框上的小徽标
- 即使在浅背景上也必须清楚可见

## 禁止项

- 禁止第二行文字，例如 `Kiki Lab`
- 禁止大号品牌标题
- 禁止角标偏离右上角
- 禁止每张图使用不同形状或不同色逻辑

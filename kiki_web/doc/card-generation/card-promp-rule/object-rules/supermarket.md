# 对象规则：超市购物

本文件定义 `超市购物` 卡片的对象摆放和易混淆防护。

## 目标对象

1. 购物车：必须是独立可见的儿童玩具购物车，建议放在前景或中景。
2. 收银台：必须包含收银机或扫码台，建议放在中后景。
3. 货架：必须是明确的超市货架，不得只是一排商品。
4. 价格标签：必须是放大的货架边缘价格牌，不能被普通包装文字替代。
5. 购物袋：必须是独立袋子，袋身清楚可见，不能只露出袋中商品。
6. 零食：必须是独立 snack pack 或 snack group，不能和购物袋混为一体。
7. 饮料：必须是一组瓶装或盒装饮料，不能混在零食中无法区分。
8. 糖果：必须是独立糖果罐、糖果盒或糖果展示区，不能和零食共用同一堆商品。

## 易混淆对象对

- `零食` vs `糖果`：零食用薯片/饼干包，糖果用彩色糖果罐或糖果盒。
- `购物袋` vs `零食`：购物袋箭头只能落在袋身，零食箭头只能落在零食包装本体。
- `饮料` vs `零食`：饮料应使用瓶子/盒装液体形态，和袋装零食分开。
- `货架` vs `价格标签`：货架箭头指向架体，价格标签箭头指向放大的价格牌。

## 构图建议

- 购物车放前景左侧或中心偏左。
- 收银台放中后景右侧。
- 货架放左右两侧形成空间。
- 购物袋、零食、饮料、糖果分散在不同区域。
- 价格标签要足够大，避免被识别成货架上的普通装饰。

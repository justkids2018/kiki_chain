# App Icon Prompt - Summer (xhdpi)

用途：生成移动端简洁版夏季图标（Android xhdpi 目标）。

## Output Spec

- Canvas: 180x180 px
- Aspect ratio: 1:1
- Style: clean, simple, readable at small size
- Keep safe margin: main subject stays within center 80% area
- Flat-to-soft-3D hybrid, avoid over-detailed tiny objects

## Prompt

Design a clean educational mobile app icon for kids language learning.
Square icon, rounded-corner container, simple composition, high readability at 180x180.

Fixed character cast:
- one 10-year-old older sister with long loose hair
- one 4-year-old younger sister with two ponytails, younger and cuter proportions
- one cute white kitten, clearly visible

Season and outfit:
- summer version
- older sister: light summer outfit (dress or short-sleeve overalls)
- younger sister: summer outfit, skirt-priority, can be dress or pinafore

Brand rule:
- only one text label: Hi Kiki
- single line only
- small top-right badge style, low visual weight
- no second line, no slogan

Visual direction:
- warm cream + fresh green accent
- friendly smiling faces
- minimal learning cue (e.g. one simple book shape or one letter block)
- avoid clutter, keep icon simple and memorable

## Negative Prompt

too many objects, complex background, missing kitten, wrong ages, older sister not loose hair, younger sister not twin ponytails, dark style, horror mood, aggressive cat, adult makeup, mature fashion, extra text, slogan text, watermark, logo duplication, blurry, noisy, unreadable at small size

## Export Notes

- Primary deliverable: 180x180 PNG
- Optional density set from same design:
  - mdpi 48x48
  - hdpi 72x72
  - xhdpi 96x96
  - xxhdpi 144x144
  - xxxhdpi 192x192

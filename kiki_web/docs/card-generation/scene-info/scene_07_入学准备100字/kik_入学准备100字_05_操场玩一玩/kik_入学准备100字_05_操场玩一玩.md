# 操场玩一玩 — 入学准备100字学习卡片 Prompt

> 分类：入学准备100字
> 主题序号：7.5
> 目标：在操场/游乐区场景中认识方位、大小和动作

---

```text
**操场玩一玩** (主题): Hi Kiki

### I. Canvas & Style Lock
- Exact 1024x1024 square
- Premium toy-diorama playground, bright and active
- Safe, soft, rounded equipment, no dangerous sports intensity

### II. Scene Background
Create a cheerful playground with a slide, low climbing steps, soft grass, a ball, and children moving safely. The scene should make up/down, big/small, high/low, run/jump/play visible through clear poses and object comparisons.

### III. Character Cast
Use Mimi + Kiki + Jack. Jack wears a visible baseball cap. Yuki may be absent to keep the playground action uncluttered.

### IV. 10 Target Vocabulary Objects
- [shàng] / 上 / Up (/ʌp/)
- [xià] / 下 / Down (/daʊn/)
- [dà] / 大 / Big (/bɪɡ/)
- [xiǎo] / 小 / Small (/smɔːl/)
- [gāo] / 高 / High (/haɪ/)
- [dī] / 低 / Low (/loʊ/)
- [pǎo] / 跑 / Run (/rʌn/)
- [tiào] / 跳 / Jump (/dʒʌmp/)
- [wán] / 玩 / Play (/pleɪ/)
- [qiú] / 球 / Ball (/bɔːl/)

Object placement map:
1. 上 — Kiki climbing up slide steps, arrow lands on upward step action.
2. 下 — slide downward path with a toy arrow shape, arrow lands on down direction on slide.
3. 大 — large ball or large block.
4. 小 — small ball or small block beside the big one.
5. 高 — high part of slide/climber.
6. 低 — low step or low platform.
7. 跑 — Jack running on safe track.
8. 跳 — Kiki or Jack jumping over a soft hoop.
9. 玩 — children playing together near equipment.
10. 球 — colorful ball in foreground.

Critical placement rules:
- Abstract words must have concrete visual anchors.
- 大/小 and 高/低 must be visible comparisons, not just label text.
- 跑/跳/玩 arrows land on body action poses.

### V. Label Cards
- [shàng] / 上 / Up
- [xià] / 下 / Down
- [dà] / 大 / Big
- [xiǎo] / 小 / Small
- [gāo] / 高 / High
- [dī] / 低 / Low
- [pǎo] / 跑 / Run
- [tiào] / 跳 / Jump
- [wán] / 玩 / Play
- [qiú] / 球 / Ball

### VI. Arrows
- 上 arrow -> lands on climbing-up action.
- 下 arrow -> lands on downward slide path.
- 大 arrow -> lands on large object.
- 小 arrow -> lands on small object.
- 高 arrow -> lands on high platform.
- 低 arrow -> lands on low platform.
- 跑 arrow -> lands on running legs/body.
- 跳 arrow -> lands on jumping body pose.
- 玩 arrow -> lands on shared play action area.
- 球 arrow -> lands on ball body.

### VII. Branding Badge
- Top-right corner: Hi Kiki

### VIII. Production Notes
- Can reuse or adapt existing playground/campus movement scenes.
- This is a special action/comparison card; keep visual anchors extra clear.
```

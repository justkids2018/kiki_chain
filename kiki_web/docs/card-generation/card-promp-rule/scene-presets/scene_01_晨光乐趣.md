# 场景预设：scene_01_晨光乐趣

本文件定义晨光乐趣类学习卡片的场景背景规则。

## 场景目标

- 画面应表达 3-6 岁儿童在幼儿园/校园中熟悉的真实生活与学习空间，例如操场晨练、升旗仪式、晨读时光、课间游戏、手工课、校园花园、教室角落、图书角、午餐时间、午睡时光、音乐律动、放学回家。
- 场景位置必须**自然可信、贴近真实幼儿园/校园**，但视觉表现仍然遵守玩具微缩场景风格。
- 目标物体应放在真实使用位置（粉笔在黑板槽里、书包挂椅背、铃鼓在地垫上），不要全部集中在展示台。

## 背景分层

- 前景：放置 2-3 个最大、最清晰、最容易点击的目标物体（通常是孩子手边的学习/活动用品）。
- 中景：放置主要人物动作（写字、跳绳、午餐、律动）和 3-4 个目标物体。
- 后景：放置空间锚点（黑板、窗户、书架、地图墙、操场跑道、花坛），但不得抢主目标。

## 氛围

- 明亮、温暖、清新、积极、健康、阳光感强。
- 主色调建议：晨光黄、清新绿、天蓝色、奶油白、薄荷绿。
- 光照偏向晨间或上午，柔和的自然光从窗户/天空进入。
- 校园场景要表达"安全、有秩序、被照顾"的幼儿园质感，不允许过度真实化的学校监控/纪录片质感。

## 物品分布原则

- 每张卡的 8 个词条建议构成：
  - **3-4 个学习/活动用品**（书包、文具盒、跳绳、铃鼓、绘本）
  - **2-3 个空间标志物**（黑板、跑道、书架、午睡床、花坛）
  - **1-2 个生活/自理用品**（水杯、围兜、餐盘、毛巾、拖鞋）
- 严禁把抽象概念（"自律""礼貌""勤奋"）作为目标词条。
- 严禁把家庭场景物品（爸爸、奶奶、家庭照片）放进校园场景。

## 易错防护

- 同一张卡内不要同时出现多个**功能极相似**的物品（"书 / 绘本"、"勺子 / 调羹"）。
- 小物体（粉笔、书签、贴纸、徽章）必须放大到可识别。
- 校园背景里大量真实存在的杂物（灭火器、电源插座、垃圾桶）不得被误当成目标物体。
- 户外场景（操场、花园）的天空和远景不允许喧宾夺主，必须为前景目标物体留出主视觉。
- 老师角色可以出现在背景，但不获得标签卡或箭头；目标词条只锁定"物品"和"姐妹+小白猫"以外的固定标的。

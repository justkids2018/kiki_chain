# 小小自然角 — 入学准备100字学习卡片 Prompt

> 分类：入学准备100字
> 主题序号：7.9
> 目标：在校园花园/公园自然场景中认识基础自然词

---

```text
**小小自然角** (主题): Hi Kiki

### I. Canvas & Style Lock
- Exact 1024x1024 square
- Premium miniature toy garden
- Gentle outdoor light, soft colors, child-friendly nature

### II. Scene Background
Create a small school garden or park nature corner. Children observe sky, sun, moon decoration, clouds, rain drops, wind ribbon, hill, stones, flowers, and tree. Since sun and moon cannot both be literal in the same daytime sky, use a moon-shaped garden ornament or picture card.

### III. Character Cast
Use Mimi + Yuki + Kiki. Keep the scene calm and observational.

### IV. 10 Target Vocabulary Objects
- [tiān] / 天 / Sky (/skaɪ/)
- [tài yáng] / 太阳 / Sun (/sʌn/)
- [yuè liang] / 月亮 / Moon (/muːn/)
- [yún] / 云 / Cloud (/klaʊd/)
- [yǔ] / 雨 / Rain (/reɪn/)
- [fēng] / 风 / Wind (/wɪnd/)
- [shān] / 山 / Hill (/hɪl/)
- [shí] / 石 / Stone (/stoʊn/)
- [huā] / 花 / Flower (/ˈflaʊər/)
- [shù] / 树 / Tree (/triː/)

Object placement map:
1. 天 — open sky area.
2. 太阳 — warm sun in sky.
3. 月亮 — moon-shaped garden ornament or wall picture.
4. 云 — soft cloud.
5. 雨 — tiny rain cloud corner or watering-rain visual.
6. 风 — wind ribbon/windmill showing wind.
7. 山 — small hill in background.
8. 石 — stones along path.
9. 花 — flowers in foreground.
10. 树 — tree on one side.

Critical placement rules:
- 月亮 must be a visible ornament/card if the scene is daytime.
- 风 must use a visual anchor like ribbon or windmill.
- 天 label points to sky, not sun or cloud.

### V. Label Cards
- [tiān] / 天 / Sky
- [tài yáng] / 太阳 / Sun
- [yuè liang] / 月亮 / Moon
- [yún] / 云 / Cloud
- [yǔ] / 雨 / Rain
- [fēng] / 风 / Wind
- [shān] / 山 / Hill
- [shí] / 石 / Stone
- [huā] / 花 / Flower
- [shù] / 树 / Tree

### VI. Arrows
- 天 arrow -> lands on open sky area.
- 太阳 arrow -> lands on sun.
- 月亮 arrow -> lands on moon ornament/card.
- 云 arrow -> lands on cloud.
- 雨 arrow -> lands on raindrops.
- 风 arrow -> lands on wind ribbon/windmill.
- 山 arrow -> lands on hill.
- 石 arrow -> lands on stone.
- 花 arrow -> lands on flower.
- 树 arrow -> lands on tree trunk/crown.

### VII. Branding Badge
- Top-right corner: Hi Kiki

### VIII. Production Notes
- Can adapt existing campus garden card.
- Keep nature elements large and clear.
```

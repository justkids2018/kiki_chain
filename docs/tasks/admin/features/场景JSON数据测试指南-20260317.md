## 常见问题

### Q: JSON 太长，文本框显示不全？
A: 可以先在编辑器中编辑好，然后复制粘贴。保存后会自动格式化。

### Q: 如何批量导入多个场景？
A: 目前需要逐个创建。未来可以考虑添加批量导入功能。

### Q: 修改 JSON 后 item_count 没更新？
A: item_count 是后端自动计算的，保存后会自动更新。

### Q: 可以不填写 JSON 吗？
A: 可以，items_data 是可选字段。不填写则 item_count 为 0。

## 🔧 技术实现细节

### 1. 物品数据结构
每个物品包含完整的学习信息：
```dart
SceneItem(
  id: 'item_xxx',           // 唯一标识
  sceneId: 'scene_xxx',     // 所属场景
  nameCn: '中文名',          // 中文名称
  nameEn: 'English Name',   // 英文名称
  pinyin: 'pīn yīn',        // 拼音
  pronunciation: 'pin1 yin1', // 发音标注
  imageUrl: 'assets/...',   // 物品图片
  audioUrl: 'assets/...',   // 发音音频
  order: 1,                 // 排序
  hotspot: {...},           // 热点坐标
)
```

### 2. 热点类型
支持两种热点形状：
- **矩形 (rect)**: 适用于规则物品
  ```dart
  hotspot: {
    'type': 'rect',
    'x': 100.0,
    'y': 150.0,
    'width': 80.0,
    'height': 120.0,
  }
  ```
- **圆形 (circle)**: 适用于圆形物品
  ```dart
  hotspot: {
    'type': 'circle',
    'x': 250.0,
    'y': 200.0,
    'radius': 50.0,
  }
  ```

### 3. 场景物品分布
- **日常用品**: 早餐、准备上学、做饭
- **个人护理**: 洗澡时间、睡前准备
- **户外活动**: 周末野餐

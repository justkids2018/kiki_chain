# 场景管理图片显示和物品管理增强

**日期**: 2026-03-17
**状态**: ✅ 已完成

## 需求概述

1. 在场景管理表格中添加互动大图列，支持图片放大预览
2. 在物品管理页面顶部显示场景详细配置信息

## 实现内容

### 1. 场景管理 - 添加互动大图列

**文件**: `kiki_admin/src/views/Scenes.vue`

**修改内容**:
- 在封面图片列后添加"互动大图"列
- 使用 `el-image` 组件显示缩略图（60x60）
- 支持点击放大预览（`:preview-src-list`）

**代码位置**: 第 42-52 行

```vue
<el-table-column prop="interactive_image" label="互动大图" width="100" align="center">
  <template #default="{ row }">
    <el-image
      v-if="row.interactive_image"
      :src="row.interactive_image"
      fit="cover"
      style="width: 60px; height: 60px; border-radius: 4px"
      :preview-src-list="[row.interactive_image]"
    />
  </template>
</el-table-column>
```

### 2. 物品管理 - 显示场景详情

**文件**: `kiki_admin/src/views/SceneItems.vue`

**修改内容**:

1. **添加场景详情卡片**（第 3-48 行）
   - 使用 `el-descriptions` 组件展示场景信息
   - 显示字段：
     - 场景名称（中英文）
     - 所属分类
     - 封面图片（支持放大）
     - 互动大图（支持放大）
     - 描述
     - 情境说明
     - 排序
     - 新标签

2. **获取分类数据**
   - 新增 `fetchCategories()` 函数
   - 通过 `computed` 属性计算分类名称
   - 在 `onMounted` 中调用

3. **数据结构**
   - 新增 `sceneDetail` ref 存储完整场景信息
   - 新增 `categories` ref 存储分类列表
   - 新增 `categoryName` computed 属性

## 技术要点

1. **图片预览功能**
   - 使用 Element Plus 的 `el-image` 组件
   - 通过 `:preview-src-list` 属性实现点击放大
   - 统一样式：60x60 缩略图，圆角 4px

2. **数据关联**
   - 场景数据包含 `category_id`
   - 通过 `computed` 属性从分类列表中查找对应名称
   - 避免后端修改，前端完成数据关联

3. **布局优化**
   - 场景详情卡片独立显示在顶部
   - 物品管理卡片在下方，保持原有功能
   - 使用 `margin-top: 20px` 分隔两个卡片

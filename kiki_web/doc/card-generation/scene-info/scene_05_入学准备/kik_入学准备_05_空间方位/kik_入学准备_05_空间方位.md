```text
**空间方位** (主题): Hi Kiki

### I. Canvas & Style Lock
- Target age: 3-6 years old
- Format: exact square 1:1
- Resolution: exact 1024x1024 pixels
- View: slightly elevated 3/4 top-front view
- Premium miniature toy diorama in a Montessori block-and-map learning area
- Use toy blocks, shelves, tunnels, arrows, and floor map positions
- Soft polished 3D materials, clear layout, child-safe and readable
- No giant title text, no inner frame, no extra border

### II. Scene Background
Create a spatial-position play scene. Use one central toy house, blocks, baskets, and a floor map so each position word is visually obvious.

Required character baseline:
- Exactly two cute sister girls: one 10-year-old older sister and one 4-year-old younger sister with two ponytails
- Exactly one cute white kitten
- Characters may point to the layout, but must not cover target position markers

### III. 8 Target Vocabulary Objects
- [shàng miàn] / 上面 / On Top (/ɑːn tɑːp/)
- [xià miàn] / 下面 / Under (/ˈʌndər/)
- [lǐ miàn] / 里面 / Inside (/ɪnˈsaɪd/)
- [wài miàn] / 外面 / Outside (/ˌaʊtˈsaɪd/)
- [qián miàn] / 前面 / In Front (/ɪn frʌnt/)
- [hòu miàn] / 后面 / Behind (/bɪˈhaɪnd/)
- [zuǒ biān] / 左边 / Left (/left/)
- [yòu biān] / 右边 / Right (/raɪt/)

Object placement map:
1. 上面 — toy ball on top of a block or shelf
2. 下面 — toy car under a table or arch
3. 里面 — toy kitten figure inside a box or tunnel
4. 外面 — toy figure outside a house or box
5. 前面 — object in front of central house
6. 后面 — object behind central house, still visible
7. 左边 — left-side marker or toy object on left side
8. 右边 — right-side marker or toy object on right side

### IV. Label Cards
Each card has exactly 3 lines:
Line 1: [pinyin]
Line 2: 汉字
Line 3: english

The 8 label cards must be exactly:
- [shàng miàn] / 上面 / On Top
- [xià miàn] / 下面 / Under
- [lǐ miàn] / 里面 / Inside
- [wài miàn] / 外面 / Outside
- [qián miàn] / 前面 / In Front
- [hòu miàn] / 后面 / Behind
- [zuǒ biān] / 左边 / Left
- [yòu biān] / 右边 / Right

### V. Arrows
- Exactly 8 arrows
- Arrows must land on the object-position relation, not just a blank area
- Use clear, short arrows and avoid crossing

### VI. Hard Constraints
- CLOSED VOCABULARY SET: use exactly the 8 words in section III
- Exactly 8 position targets, 8 label cards, 8 arrows
- Position contrasts must be unambiguous
- No citation markers or extra text in labels
```

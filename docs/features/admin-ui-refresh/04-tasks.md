# Kiki 管理后台 UI 升级任务拆分

## 关联

- [需求](01-requirement.md) · [分析](02-analysis.md) · [设计](03-design.md)

## Task 1：建立后台视觉变量

| 项 | 内容 |
|---|---|
| 目的 | 清理 Vite 模板样式，建立 Kiki 自有设计变量和基础覆盖 |
| 覆盖 | R-3、R-4 |
| 文件 | `kiki_admin/src/style.css`、`kiki_admin/src/main.ts` |
| 规模 | ≤ 200 行，2 个文件 |
| 验证 | `npm run build`，登录页和后台基础样式冒烟 |
| 风险 | 全局覆盖影响旧页，使用 `.kiki-admin` 命名空间隔离 |

## Task 2：升级公共后台壳层

| 项 | 内容 |
|---|---|
| 目的 | 实现浅色侧栏、顶部栏、页面画布和侧栏收起 |
| 覆盖 | R-1、R-3、R-4 |
| 文件 | `kiki_admin/src/views/Layout.vue` |
| 规模 | ≤ 200 行，1 个文件 |
| 依赖 | Task 1 |
| 验证 | 导航、账户菜单、退出和多宽度布局手测 |
| 风险 | 公共布局影响全站，保留现有路由和认证代码 |

## Task 3：改造用户管理示范页

| 项 | 内容 |
|---|---|
| 目的 | 完成标题说明、筛选工具条、紧凑表格与分层操作按钮 |
| 覆盖 | R-2、R-4、R-6 |
| 文件 | `kiki_admin/src/views/Users.vue` |
| 规模 | ≤ 200 行，1 个文件 |
| 依赖 | Task 1、Task 2 |
| 验证 | 列表、搜索、重置、刷新、详情、编辑、长文本和窄窗口 |
| 风险 | 无分页 API，保持现有前端数据能力，不伪造服务端逻辑 |

## 执行顺序与整体验收

```text
Task 1 → Task 2 → Task 3 → 全页面冒烟与视觉截图
```

- [ ] 每个 Task 独立构建并留存运行证据。
- [ ] 用户管理所有现有业务交互无回归。
- [ ] 1440px、1280px 和窄窗口布局可用。
- [ ] 公共壳层下其他页面可进入和操作。
- [ ] 不修改 API、数据库和服务端逻辑。

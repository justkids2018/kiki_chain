# 成长树场景列表

## 目的

将主题下原有的横向层叠场景列表替换为纵向成长树样式，让孩子更容易感知场景之间的前进方向，同时保持现有学习流程不变。

## 页面边界

用户流程保持为：

```text
首页主题页 -> 成长树场景列表 -> 互动学习卡片
```

- 首页主题页的布局和业务逻辑不变。
- 成长树页面继续复用 `SceneListController` 加载场景、恢复上次位置和执行导航。
- 所有节点始终可点击，不在场景层设置锁定或每日学习上限。
- 不新增进度 API，复用现有全量进度和学习提交接口。

## 视觉与交互

- 场景按照原有顺序沿中央树干向上排列，节点左右交替。
- 页面从下向上滚动，表达树木持续生长的方向。
- 待探索节点使用浅色和空心嫩芽，已学节点使用亮色、勾章和实际星数，当前节点使用绿色呼吸环。
- 节点不显示“已学习/未学习”文字，也不使用锁图标，避免让孩子误以为不可点击。
- 场景节点使用现有封面图，网络图片失败时回退为叶片图标。
- 页面背景叠加草地、花丛和灌木素材，降低中央树干两侧的空白感。
- Yuki / Kiki / Mimi 使用独立生成的透明背景地图角色素材，角色设定参考学习卡片统一角色规范。
- 角色只作为地图环境的一部分，不是新的功能入口，不改变学习任务、复习奖励或场景解锁逻辑。
- 页面顶部只保留分类标题与场景数量，不再显示额外的“选择一个场景开始学习”提示条。
- 标题栏作为透明悬浮层叠在地图上方，成长路径可从页面顶部连续延伸到底部。
- Yuki 与 Kiki 在底部草地中央坐在一起学习，Mimi 在旁边看小画架，三者形成一个完整环境小场景。
- 场景节点之间使用轻量弯曲点状路径连接，避免粗藤蔓遮挡内容或切割页面。
- 词条学习进度本地立即保存，地图一次批量读取所有场景摘要，禁止按节点逐个请求。
- 登录成功时强制恢复一次服务器全局进度；地图按 06:00、17:00、20:00 三个窗口最多各刷新一次，凌晨沿用前一晚快照。
- 服务器请求失败时保留本地和上次快照，不清空已学状态。
- 成长树底部不再追加刷新节点；仅加载失败时展示绿色重试按钮。
- 节点按下时轻微缩小，点击后仍沿现有路由进入学习卡片。
- 支持下拉刷新、加载失败重试、空状态和上次场景位置恢复。

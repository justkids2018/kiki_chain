# 走进小教室 — 入学准备100字学习卡片 Prompt

> 分类：入学准备100字
> 主题序号：7.4
> 目标：在低龄教室场景中认识基础学习用品和课堂动作

---

```text
**走进小教室** (主题): Hi Kiki

### I. Canvas & Style Lock
- Exact 1024x1024 square
- Premium Montessori classroom toy diorama
- Warm, tidy, low-age friendly, not a realistic classroom photo

### II. Scene Background
Create a simple preschool classroom corner. Kiki sits near a small desk, Yuki reads beside her, Mimi rests near the chair. The scene includes a book, notebook, pencil, paper, desk, chair, lamp, and clear looking/listening actions.

### III. Character Cast
Use Mimi + Yuki + Kiki. No Jack; keep the first classroom card calm and simple.

### IV. 10 Target Vocabulary Objects
- [shū] / 书 / Book (/bʊk/)
- [běn] / 本 / Notebook (/ˈnoʊtbʊk/)
- [bǐ] / 笔 / Pencil (/ˈpensəl/)
- [zhǐ] / 纸 / Paper (/ˈpeɪpər/)
- [zhuō zi] / 桌子 / Table (/ˈteɪbəl/)
- [yǐ zi] / 椅子 / Chair (/tʃer/)
- [dēng] / 灯 / Lamp (/læmp/)
- [zuò] / 坐 / Sit (/sɪt/)
- [kàn] / 看 / Look (/lʊk/)
- [tīng] / 听 / Listen (/ˈlɪsən/)

Object placement map:
1. 书 — open picture book on desk.
2. 本 — notebook beside the book.
3. 笔 — large pencil near notebook.
4. 纸 — loose sheet of paper.
5. 桌子 — small child desk.
6. 椅子 — child chair.
7. 灯 — small desk lamp.
8. 坐 — Kiki sitting posture on chair.
9. 看 — Kiki looking at book.
10. 听 — Yuki gently speaking while Kiki listens, use ear/attention pose as anchor.

Critical placement rules:
- 书 and 本 must be visually different: open colorful book vs plain notebook.
- 笔 and 纸 must not overlap heavily.
- 坐、看、听 must point to clear body action anchors.
```

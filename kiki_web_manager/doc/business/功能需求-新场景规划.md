## 内容制作规范

### 每个场景需要：
1. **互动大图**：1024x768px，横屏，高质量
2. **封面图**：600x600px，用于卡片展示
3. **热区JSON配置**：包含所有可点击物品的坐标和中英文信息
4. **物品数量**：建议10-20个，适合儿童注意力

### 数据格式（JSON示例）：
```json
{
  "category": "daily",
  "categoryId": "daily_001",
  "categoryName": "日常生活",
  "scenes": [
    {
      "id": "scene_daily_001",
      "name": "上学",
      "coverImage": "https://cdn.example.com/covers/go_to_school.jpg",
      "interactiveImage": "https://cdn.example.com/scenes/go_to_school.jpg",
      "itemCount": 15,
      "items": [
        {
          "id": "item_001",
          "text": "书包",
          "pinyin": "shū bāo",
          "english": "Schoolbag",
          "coordinates": [
            {"x": 100, "y": 200},
            {"x": 200, "y": 200},
            {"x": 200, "y": 300},
            {"x": 100, "y": 300}
          ]
        }
      ]
    }
  ]
}
```

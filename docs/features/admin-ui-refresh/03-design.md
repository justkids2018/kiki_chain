# Kiki 管理后台 UI 升级设计

## 关联需求

- [01-requirement.md](01-requirement.md)，覆盖 R-1 至 R-6。
- [02-analysis.md](02-analysis.md)。

## 整体方案与架构定位

以 `kiki_admin` 自有 CSS 变量建立视觉基础，在 `Layout.vue` 完成公共后台壳层，在 `Users.vue` 完成首个业务示范页。依赖方向保持为页面组件 → 现有 API 模块 → 后端契约，视觉层不进入 API、认证或业务状态层。

```text
Kiki 设计变量 → 公共 Layout → Users 页面表现
                              ↓
                    现有 userAPI 与业务交互
```

不引入新运行依赖，不修改路由、数据库或 API。实现遵循项目现有 Vue 组件边界与 `docs/api/` 契约。

## 视觉主题

- **Visual thesis**：克制、清晰、友好的轻量运营工作台，以淡蓝灰画布和清爽白色功能面板承载高密度信息。
- **Content plan**：先定位页面，再提供筛选操作，最后展示可扫描的数据与明确行操作。
- **Interaction thesis**：菜单和按钮使用短促的颜色、位移与缩放反馈，侧栏收起保持平滑且尊重减少动态效果设置。

参考同类：Linear 的导航密度和清晰选中态，Notion 的低装饰内容层级，飞书管理后台的中文信息可读性。仅吸收成熟模式，不引入其代码或业务结构。

## 颜色、字体与设计变量

- 品牌描述：亲切、可信、轻盈。
- 字体：中文优先 `PingFang SC`，回退 `Microsoft YaHei` 与系统无衬线字体，适合中文密集表格且不新增字体网络依赖。
- 色彩使用 OKLCH：品牌蓝 `oklch(62% 0.18 252)`，画布 `oklch(97% 0.012 245)`，侧栏 `oklch(98.5% 0.006 245)`，主文字 `oklch(28% 0.025 255)`，弱文字 `oklch(56% 0.025 255)`，分隔线 `oklch(91% 0.012 245)`。
- 圆角体系：4px 控件细节、8px 按钮输入框、12px 内层面板、18px 页面容器、999px 状态标签。
- 间距体系：4、8、12、16、20、24、32px。

## 组件样式

- 侧栏：216px 展开、72px 收起，浅色背景，品牌区与菜单分层，选中项使用浅蓝填充和品牌蓝文字。
- 顶部栏：64px，白色表面与底部分隔，左侧页面标题，右侧账户入口。
- 页面画布：24px 内边距，使用颜色层级区分画布和白色业务面板。
- 筛选面板：标题说明位于上部，工具条独立成行，搜索为主、重置和刷新为辅。
- 表格：无厚重外框，表头弱底色，数字使用等宽数字，长 UID 单行截断并保留提示。
- 按钮：统一 8px 圆角与至少 40px 热区，按下缩放至 0.96，查看为次级、编辑为品牌主色。

## 布局、深度与响应式

- 使用普通 CSS 变量加 Vue scoped CSS，不引入第二套样式框架。
- 层级由背景色台阶与两级克制阴影表达，不使用玻璃拟态或装饰渐变。
- 1280px 以上显示完整侧栏，较窄窗口允许收起；表格不足宽度时横向滚动，不压缩关键操作。
- 交互目标不小于 40px，键盘焦点可见，图标按钮提供 `aria-label`。

## 关键决策

1. 选择“设计变量 + 现有组件覆盖”，而非替换 Element Plus，降低回归与包体风险。
2. 只升级表现层，不复制参考站 DOM 或业务能力，确保 Kiki 架构和产品逻辑独立。
3. 先公共壳层、后用户页，公共基础可复用，同时限制首阶段影响面。
4. 保留现有详情与编辑对话框，因为它们是已存在且需要聚焦的短任务，不扩大交互重构范围。

## 风险、回滚与验证

- 中风险：全局变量和组件覆盖波及旧页。必须使用 `.kiki-admin` 命名空间并进行全部菜单冒烟验证。
- 中风险：侧栏布局在窄宽度下溢出。验证 1440px、1280px 和窄窗口状态。
- 低风险：颜色在不同屏幕下层级不足。以截图和可读性检查校准。
- 回滚：三个实现任务均保持独立文件边界，可逐任务撤回，不涉及数据回滚。
- 验证：`npm run build`，用户列表加载、搜索、重置、刷新、详情、编辑，以及主要页面导航和截图对比。

## 设计约束

- 做：保留 Kiki 文案和业务字段；使用统一变量；保障长中文与 UID；复用现有 API。
- 不做：逐像素复制；增加参考站品牌资源；使用紫蓝渐变；修改权限和数据流；伪造分页或角色操作。

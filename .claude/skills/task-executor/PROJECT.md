## 🎯 Hi Kiki 任务池结构

### 任务池位置

```
docs/tasks/
├── TASK_BOARD.md          # 任务看板（总览）
├── backend/               # 后端任务
│   ├── backlog.md        # 后端任务池
│   └── features/         # 具体任务文件
├── app/                   # 移动端任务
│   ├── backlog.md
│   └── features/
└── admin/                 # 管理后台任务
    ├── backlog.md
    └── features/
```

### 任务文件格式

```markdown
# [任务标题]

**优先级**: P0/P1/P2/P3
**状态**: 📝 待办 / 🚀 进行中 / ✅ 完成
**涉及端**: 后端 / 移动端 / 管理后台
**预计时间**: X 小时
**创建时间**: YYYY-MM-DD

## 需求描述
[详细描述]

## 技术方案
[实现方案]

## 依赖关系
- 依赖: [其他任务]

## 自动化执行
是否允许自动执行？ [x] 是 [ ] 否

执行策略：
- [x] 自动生成契约
- [x] 自动生成代码框架
- [ ] 自动补充业务逻辑（需人工）
- [x] 自动生成测试

## 验收标准
- [ ] 标准 1
- [ ] 标准 2
```

### 任务依赖规则

**后端任务依赖**:
- 数据库迁移 → 后端实现
- 契约定义 → 代码生成
- API 实现 → 前端集成

**前端任务依赖**:
- 后端 API → 前端实现
- 数据模型 → UI 实现

**跨端任务依赖**:
- 后端优先于前端
- 移动端和管理后台可并行

## 🔄 执行流程

### 标准执行流程

```
1. 扫描任务池
   ↓
2. 过滤可执行任务（状态=待办，允许自动执行，依赖已完成）
   ↓
3. 分析依赖关系
   ↓
4. 生成执行计划
   ↓
5. 用户确认
   ↓
6. 逐个执行任务
   ↓
7. 更新任务状态
   ↓
8. 生成执行报告
```

### Skills 调用链

**后端任务**:
```
/contract-manager → /code-generator →
kiki_server/code-implementation → kiki_server/code-review
```

**前端任务**:
```
/code-generator →
kiki_web/code-implementation → kiki_web/code-review
```

**全栈任务**:
```
/orchestrator → /contract-manager → /code-generator →
后端实现 ║ 前端实现 → 集成测试
```

## 📊 任务状态管理

### 状态流转

```
📝 待办 → 🚀 进行中 → ✅ 完成
                    → ❌ 失败
                    → ⏸️ 暂停
```

### 状态更新时机

- **进行中**: 任务开始执行时
- **完成**: 所有验收标准满足时
- **失败**: 执行过程中出错时
- **暂停**: 需要人工介入时

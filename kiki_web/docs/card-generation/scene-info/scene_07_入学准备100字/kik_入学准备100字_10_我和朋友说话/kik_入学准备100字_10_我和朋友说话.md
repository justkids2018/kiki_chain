# 我和朋友说话 — 入学准备100字学习卡片 Prompt

> 分类：入学准备100字
> 主题序号：7.10
> 目标：在老师和朋友互动场景中认识基础人称、关系和表达动作

---

```text
**我和朋友说话** (主题): Hi Kiki

### I. Canvas & Style Lock
- Exact 1024x1024 square
- Premium toy-diorama classroom/play corner
- Warm emotional interaction, clear gestures, no text-heavy speech bubbles

### II. Scene Background
Create a gentle classroom play corner where Kiki talks with a friend and a teacher. Yuki helps nearby, Mimi sits between them. The card focuses on simple social words: you, he, person, friend, teacher, good, smile, cry, speak, can.

### III. Character Cast
Use Mimi + Yuki + Kiki + Jack. Jack is the friend figure, with visible baseball cap. Add one teacher figure only because 老师 is a target word; keep total composition readable.

### IV. 10 Target Vocabulary Objects
- [nǐ] / 你 / You (/juː/)
- [tā] / 他 / He (/hiː/)
- [rén] / 人 / Person (/ˈpɜːrsən/)
- [péng yǒu] / 朋友 / Friend (/frend/)
- [lǎo shī] / 老师 / Teacher (/ˈtiːtʃər/)
- [hǎo] / 好 / Good (/ɡʊd/)
- [xiào] / 笑 / Smile (/smaɪl/)
- [kū] / 哭 / Cry (/kraɪ/)
- [shuō] / 说 / Speak (/spiːk/)
- [huì] / 会 / Can (/kæn/)

Object placement map:
1. 你 — Kiki points gently toward Yuki or viewer-side friend; use a “you” gesture anchor.
2. 他 — Jack as the boy friend, label points to Jack.
3. 人 — simple person-shaped classroom poster or small people icon, not any target character.
4. 朋友 — Kiki and Jack sharing a toy/book together.
5. 老师 — friendly teacher figure near a small board.
6. 好 — thumbs-up gesture or good sticker card.
7. 笑 — smiling face expression on Kiki or Jack.
8. 哭 — small emotion card with crying face, not making the real child distressed.
9. 说 — speaking gesture with a tiny soft speech bubble without readable extra text.
10. 会 — child successfully stacking blocks/raising hand “I can” gesture.

Critical placement rules:
- Abstract/social words must use visible gesture or icon anchors.
- Do not add readable Chinese/English text inside speech bubbles other than target labels.
- 老师 can be an extra adult because it is a target; keep her simple and not dominant.

### V. Label Cards
- [nǐ] / 你 / You
- [tā] / 他 / He
- [rén] / 人 / Person
- [péng yǒu] / 朋友 / Friend
- [lǎo shī] / 老师 / Teacher
- [hǎo] / 好 / Good
- [xiào] / 笑 / Smile
- [kū] / 哭 / Cry
- [shuō] / 说 / Speak
- [huì] / 会 / Can

### VI. Arrows
- 你 arrow -> lands on the “you” pointing gesture/person anchor.
- 他 arrow -> lands on Jack's body.
- 人 arrow -> lands on person-shaped poster/icon.
- 朋友 arrow -> lands on shared friend interaction area.
- 老师 arrow -> lands on teacher body.
- 好 arrow -> lands on thumbs-up/good sticker.
- 笑 arrow -> lands on smiling face.
- 哭 arrow -> lands on crying emotion card.
- 说 arrow -> lands on speaking gesture/speech bubble anchor.
- 会 arrow -> lands on successful “I can” action pose.

### VII. Branding Badge
- Top-right corner: Hi Kiki

### VIII. Production Notes
- This is the most abstract card in the series. Keep icons/gestures extra clear.
- If image generation becomes cluttered, split this card later into “我和朋友” and “表情动作”.
```

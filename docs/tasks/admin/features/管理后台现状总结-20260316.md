## 🏗️ 技术架构

### 前端技术栈
```
Vue 3 (Composition API)
├── Vite (构建工具)
├── Element Plus (UI 组件库)
├── Pinia (状态管理)
├── Vue Router (路由管理)
├── Axios (HTTP 客户端)
└── TypeScript (类型系统)
```

### 目录结构
```
kiki_admin/
├── src/
│   ├── api/          # API 接口定义
│   │   ├── auth.ts
│   │   ├── categories.ts
│   │   ├── scenes.ts
│   │   ├── items.ts
│   │   ├── users.ts
│   │   └── request.ts
│   ├── views/        # 页面组件
│   │   ├── Login.vue
│   │   ├── Layout.vue
│   │   ├── Dashboard.vue
│   │   ├── Categories.vue
│   │   ├── Scenes.vue
│   │   ├── SceneItems.vue
│   │   └── Users.vue
│   ├── router/       # 路由配置
│   ├── stores/       # Pinia 状态管理
│   ├── types/        # TypeScript 类型定义

```

### API 端点对接

**认证**
- POST `/api/v1/auth/login` ✅

**用户管理**
- GET `/api/v1/admin/users` ✅
- GET `/api/v1/admin/users/:id` ✅

**场景分类**
- GET `/api/v1/admin/scene/categories` ✅
- POST `/api/v1/admin/scene/categories` ✅
- PUT `/api/v1/admin/scene/categories/:id` ✅
- DELETE `/api/v1/admin/scene/categories/:id` ✅

**场景管理**
- GET `/api/v1/admin/scene/scenes` ✅
- POST `/api/v1/admin/scene/scenes` ✅
- GET `/api/v1/admin/scene/scenes/:id` ✅
- PUT `/api/v1/admin/scene/scenes/:id` ✅
- DELETE `/api/v1/admin/scene/scenes/:id` ✅

**场景物品**
- GET `/api/v1/admin/scene/scenes/:id/items` ✅
- POST `/api/v1/admin/scene/scenes/:id/items` ✅
- PUT `/api/v1/admin/scene/items/:id` ✅
- DELETE `/api/v1/admin/scene/items/:id` ✅

## 📝 注意事项

1. **kiki_web_manager** (Flutter) 已废弃，不再使用
2. **kiki_admin** (Vue) 是当前唯一的管理后台
3. 所有管理功能都通过 `/api/v1/admin/*` 端点访问
4. 需要 Admin 角色的 JWT Token 才能访问管理端 API

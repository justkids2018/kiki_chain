# 组件规范索引

这个目录只负责跨场景复用的视觉组件规则，不负责背景布局或场景主题。

## 职责边界

这些文件只回答组件怎么长、怎么配色、怎么摆、怎么保持一致。

不在这里定义：

- 场景背景
- 展示面类型
- 8 个目标词内容
- 场景氛围
- 物体层布局

这些内容仍然由主 PRO 决定。

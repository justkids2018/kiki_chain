# Hi Kiki 项目需求文档

> 版本：1.0  
> 更新日期：2026-07-12  
> 文档目的：从当前产品实现反向归纳 Hi Kiki 的产品定位、用户体验、功能边界与验收标准。

## 1. 功能概述

Hi Kiki 是一套面向儿童启蒙阶段的横屏互动学习产品，以生活、校园、故事和探索场景为载体，将汉字、英文词汇、语音、笔顺与学习记录组合成可操作、可反馈、可持续追踪的学习体验，并为家长和运营人员提供成长查看及内容管理能力。

产品由儿童学习 App、业务服务、运营管理后台和品牌下载站共同组成。

## 2. 产品目标

- 让儿童通过“看场景、点物体、听发音、认词语、练书写”完成低门槛启蒙学习。
- 让学习内容可按主题与学习卡片持续扩充，而不依赖频繁发布新版 App。
- 记录儿童学习轨迹，为成长回顾和后续个性化学习提供基础。
- 让运营人员能够维护主题、学习卡片、词条、图片热区和用户反馈。
- 通过 VIP 订阅为高级内容与权益提供商业化入口。

## 3. 目标用户与使用场景

### 3.1 儿童学习者

- 在家长协助完成登录后，自主选择感兴趣的主题和学习卡片。
- 点击场景中的物体，查看中英文词语并听取发音。
- 针对汉字进入书写练习，通过笔顺演示与描写加深记忆。

使用前提：设备支持横屏展示；首次使用时需要网络完成登录和内容加载；部分已经加载的资源可通过本地缓存改善再次访问体验。

### 3.2 家长或监护人

- 为孩子注册或登录账号。
- 查看孩子已学习的内容和整体进度。
- 处理版本更新、订阅权益以及问题反馈。

### 3.3 内容运营人员

- 创建学习主题与学习卡片。
- 上传卡片图片，维护词条及其点击热区。
- 查看用户、学习数据和反馈处理状态。

## 4. 页面结构与功能拆解

### 4.1 启动与身份入口

展示内容：

- 品牌启动画面与加载状态。
- 登录状态检查结果。
- 登录入口、注册入口及必要的输入项。

交互操作：

**登录**

- 触发条件：用户未登录或登录凭证失效。
- 操作步骤：输入账号信息并提交。
- 系统响应：校验身份；成功后进入学习首页，失败时保留输入并展示原因。

**注册**

- 触发条件：用户没有可用账号。
- 操作步骤：进入注册页，填写必要信息并提交。
- 系统响应：创建账号并建立登录状态；信息不合法或账号已存在时给出提示。

状态说明：启动时显示加载状态；网络异常时允许用户重试；有效登录状态直接进入首页。

### 4.2 学习首页

展示内容：

- 适合儿童识别的主题入口。
- 当前用户与基础操作入口。
- 成长轨迹、订阅权益、帮助反馈等辅助入口。
- 内容加载、无内容和异常状态。

交互操作：

**选择学习主题**

- 触发条件：主题列表加载成功。
- 操作步骤：点击主题卡片。
- 系统响应：进入该主题下的学习卡片列表。

**查看成长轨迹**

- 触发条件：用户处于登录状态。
- 操作步骤：进入成长或学习记录入口。
- 系统响应：汇总并展示已学习内容与完成情况。

**进入会员中心**

- 触发条件：订阅入口可见。
- 操作步骤：点击会员入口。
- 系统响应：展示当前权益、可购买产品与购买操作。

状态说明：首次加载显示等待反馈；无主题时显示空态；服务异常时显示可理解的错误与重试入口。

### 4.3 主题学习卡片列表

展示内容：

- 当前主题名称与视觉信息。
- 主题下的学习卡片列表。
- 每张卡片的封面、名称、学习状态或进度提示。

交互操作：

**打开学习卡片**

- 触发条件：卡片可用，且用户满足对应权限要求。
- 操作步骤：点击卡片。
- 系统响应：加载卡片详情与互动资源，进入场景学习页。

**返回主题选择**

- 触发条件：用户位于卡片列表。
- 操作步骤：点击返回。
- 系统响应：回到学习首页并保留合理的浏览位置。

状态说明：没有卡片时说明该主题暂无内容；受限内容需明确提示所需权益；加载失败时支持重试。

### 4.4 互动场景学习

展示内容：

- 横屏场景图片。
- 可点击的物体热区及学习提示。
- 当前词条的中文、英文和相关音频信息。
- 上一项、下一项、返回与书写练习等操作入口。

交互操作：

**点击场景物体**

- 触发条件：场景及词条数据加载完成。
- 操作步骤：点击图中被标注的物体。
- 系统响应：突出显示目标，展示对应中英文词条并播放或提供语音。

**播放发音**

- 触发条件：词条存在可用音频。
- 操作步骤：点击发音入口。
- 系统响应：播放目标语言音频；播放失败时不阻断继续学习。

**进入书写练习**

- 触发条件：当前词条包含可练习汉字。
- 操作步骤：点击书写入口。
- 系统响应：进入对应汉字的笔顺和描写页面。

**结束本次学习**

- 触发条件：用户主动返回或完成当前学习过程。
- 操作步骤：点击返回或完成。
- 系统响应：保存本次学习进度并返回卡片列表；App 从后台恢复时，详情页回到安全的列表层级。

状态说明：图片加载时显示占位；音频不可用时保留文字学习；进度上报失败可提示重试或延后同步。

### 4.5 汉字书写练习

展示内容：

- 当前汉字及规范书写区域。
- 笔顺动画、笔画提示和练习反馈。
- 重播、清除、返回等操作。

交互操作：

**观看笔顺**

- 触发条件：当前汉字存在笔顺数据。
- 操作步骤：播放或重播笔顺。
- 系统响应：按正确顺序展示笔画过程。

**进行描写**

- 触发条件：书写区域可用。
- 操作步骤：按提示在区域内书写。
- 系统响应：呈现书写轨迹并提供即时反馈。

状态说明：笔顺资源缺失时仍展示汉字与返回入口；设备尺寸变化时保持主要书写区域可用。

### 4.6 成长与学习记录

展示内容：

- 已学习主题、卡片与词条的汇总。
- 学习进度、最近学习或累计学习信息。
- 无记录与加载失败状态。

交互操作：

**查看学习汇总**

- 触发条件：用户已登录。
- 操作步骤：进入成长页。
- 系统响应：读取用户学习记录并按业务维度汇总展示。

### 4.7 VIP 订阅

展示内容：

- 当前会员状态和权益。
- 可购买的订阅产品、价格、周期和适用渠道。
- 下单、确认与结果提示。

交互操作：

**查看权益**

- 触发条件：用户已登录。
- 操作步骤：进入会员中心。
- 系统响应：展示当前权益及有效期。

**购买订阅**

- 触发条件：存在当前地区、平台和渠道可购买的产品。
- 操作步骤：选择产品并确认购买。
- 系统响应：创建订单，调用对应支付流程，确认结果后刷新会员权益。

状态说明：无可售产品时不展示无效购买按钮；支付处理中避免重复下单；失败、取消和成功结果分别提示。

### 4.8 帮助与反馈

展示内容：问题描述输入、联系方式等辅助信息及提交状态。

交互操作：

**提交反馈**

- 触发条件：反馈内容满足最小输入要求。
- 操作步骤：填写问题并提交。
- 系统响应：保存反馈并提示提交成功；失败时保留用户输入以便重试。

### 4.9 运营管理后台

展示内容：登录页、数据总览、主题管理、学习卡片管理、卡片词条与热区编辑、用户管理、反馈管理。

交互操作：

**维护主题**

- 触发条件：管理员已登录。
- 操作步骤：新增、编辑、排序或删除主题。
- 系统响应：校验后保存；存在关联内容或不允许删除时说明原因。

**维护学习卡片**

- 触发条件：管理员已登录且主题存在。
- 操作步骤：创建或编辑卡片，上传图片并配置展示信息。
- 系统响应：保存后使移动端能够按发布规则读取最新内容。

**维护词条与热区**

- 触发条件：学习卡片已创建。
- 操作步骤：在图片上标记目标区域，配置中英文词条与音频等学习信息。
- 系统响应：保存坐标和学习内容，并提供可复核的展示结果。

**处理反馈**

- 触发条件：存在用户反馈。
- 操作步骤：查看详情并更新处理状态。
- 系统响应：保存处理进度，支持后续追踪。

状态说明：未授权访问重定向至登录；列表支持加载、空态和错误反馈；提交过程中防止重复操作。

### 4.10 品牌与下载站

展示内容：品牌介绍、产品介绍、App 下载入口、二维码及版本信息。

交互操作：

**查看和下载产品**

- 触发条件：用户访问品牌或产品页面。
- 操作步骤：浏览介绍并选择下载入口。
- 系统响应：展示适配的下载信息；App 可读取版本信息判断是否需要提示更新。

## 5. 功能范围

### 5.1 包含范围

- 用户注册、登录与登录状态维护。
- 主题、学习卡片、词条和热区驱动的场景式学习。
- 中英文展示、音频播放和汉字笔顺练习。
- 学习进度记录与成长汇总。
- VIP 产品、订单确认与权益查询。
- 用户反馈提交与后台处理。
- 运营后台的内容、用户和数据管理。
- 品牌介绍、App 下载和版本更新信息。

### 5.2 不包含范围

- 教师布置作业、班级管理与校内教务流程。
- 实时课堂、视频课程或多人互动。
- 面向第三方机构的开放内容交易市场。
- 文档中未形成完整产品闭环的历史接口设想。

## 6. 验收标准

- 当未登录用户启动 App 时，系统应引导其登录或注册；当登录凭证有效时，应直接进入学习首页。
- 当主题与卡片数据可用时，儿童选择主题后应看到对应卡片，并能进入互动场景。
- 当儿童点击有效热区时，系统应展示正确的中英文词条，并在音频可用时完成播放。
- 当儿童结束一次学习时，系统应保存该用户对应卡片的学习进度，并能在成长页查询到。
- 当汉字存在笔顺资源时，用户进入书写练习后应能查看笔顺并完成描写。
- 当用户查看会员中心时，系统应按地区、平台和渠道返回可售产品及当前权益。
- 当支付确认成功时，系统应更新订单结果并刷新用户权益；重复确认不得产生重复权益。
- 当管理员完成主题、卡片和词条维护时，移动端应能按发布规则读取对应内容。
- 当管理员未登录访问受保护页面时，系统应跳转至后台登录页。
- 当用户提交有效反馈时，后台应能查询该反馈并更新处理状态。

## 7. 限制与约束

- 移动端以横屏、沉浸式学习为主要体验基线。
- 登录态、会员权益和管理后台操作必须经过身份校验。
- 场景图、音频和笔顺属于外部资源依赖；单项资源失败不应造成整个 App 崩溃。
- 热区必须与目标图片尺寸和视觉对象保持一致，否则会导致误触或词图不符。
- 订阅产品受地区、平台、分发渠道和支付渠道共同约束。
- 内容删除需考虑已有关联词条、学习记录和历史订单的可追溯性。
- 用户隐私、儿童数据和支付信息应遵循最小采集、最小暴露与安全存储原则。

## 🎯 你的核心问题

你说："**我觉得有点控制不住，总是在失控中**"

这是因为：
1. ❌ 没有明确的协作模式
2. ❌ 不知道什么时候该做什么
3. ❌ AI 做了很多，但你不知道如何参与
4. ❌ 文档多了，但不知道如何使用

**解决方案**：建立一个清晰的"你-AI"协作模式

---

## ✅ 推荐的协作模式

### 模式：你是"产品经理" + AI 是"全栈工程师"

```
你 (产品经理)              AI (全栈工程师)
      ↓                          ↓
   提需求                      理解需求
      ↓                          ↓
   定优先级                   分解任务
      ↓                          ↓
   审核方案                   实现代码
      ↓                          ↓
   验收功能                   自我测试
      ↓                          ↓
   给出反馈                   调整优化
      ↓                          ↓
   确认完成                   更新文档
```

## 🎯 你的 4 个核心职责

### 1. 定义需求 (每天 5-10 分钟)

**你的工作:**
- 想清楚要做什么功能
- 用一句话说清楚
- 告诉 AI

**示例:**
```
✅ "我要添加用户头像上传功能"
✅ "我要实现场景搜索，可以按名字和标签搜索"
✅ "修复登录页面的卡顿问题"
```

**不要:**
```
❌ "做个功能"
❌ "优化一下"
❌ "好像有问题"
```

### 2. 确认方案 (每次 2-5 分钟)

**AI 会给你方案:**
```markdown
📋 任务分解:

1. BACKEND-FEAT-XXX: 实现上传 API
   - 文件存储
   - 图片压缩
   - 预计: 4小时

2. APP-FEAT-XXX: 实现头像上传
   - 选择图片
   - 上传显示
   - 预计: 3小时

总预计: 7小时 (约1天)

是否开始实现？
```

**你只需要:**
```
选项 A: "可以，开始吧"
选项 B: "我还想要 XXX 功能"
选项 C: "等等，我想改成 XXX"
```

### 3. 验收功能 (每次 10-20 分钟)

**AI 完成后会通知你:**
```
✅ 功能完成！请验收：

测试步骤：
1. 步骤1
2. 步骤2
3. 步骤3

预期结果：
- 结果1
- 结果2
```

**你的工作:**
1. 按照步骤测试
2. 检查是否符合预期
3. 给出反馈

**反馈模板:**
```markdown
【验收结果】
✅ 功能正常 / ❌ 有问题

【问题】(如果有)
1. 问题1
2. 问题2

【建议】(可选)
- 建议1
```

### 4. 设定优先级 (每周 10 分钟)

**每周一，排列本周任务优先级:**
```markdown
本周任务优先级:

🔴 P0 - 必须完成
1. [功能1]
2. [功能2]

🟡 P1 - 重要但可延后
3. [功能3]

🟢 P2 - 优化改进
4. [功能4]
```

## 📊 如何掌控项目进度

### 每天看这 3 个指标

#### 1. 任务完成率

```bash
# 查看任务看板
cat docs/tasks/TASK_BOARD.md
```

看这几个数字：
```
待办: X 个
进行中: Y 个
已完成: Z 个

完成率: Z / (X+Y+Z) × 100%
```

**健康指标:**
- ✅ 完成率 > 60% - 很好
- ⚠️ 完成率 30-60% - 正常
- ❌ 完成率 < 30% - 需要调整

#### 2. 当前进行中的任务

```markdown
🔥 进行中:
- APP-FEAT-001: 实现XXX功能 (进度: 70%)
- BACKEND-FEAT-002: 实现XXX API (进度: 50%)
```

**健康指标:**
- ✅ 1-3 个任务 - 刚好
- ⚠️ 4-5 个任务 - 有点多
- ❌ > 5 个任务 - 太分散了

#### 3. 待办任务数量

```markdown
📝 高优先级待办: X 个
```

**健康指标:**
- ✅ 3-5 个 - 刚好
- ⚠️ 6-10 个 - 可以接受
- ❌ > 10 个 - 需要清理

### 每周回顾 (周日晚上，10 分钟)

```markdown
## 本周回顾 (第 X 周)

### 完成了什么
- [x] 功能1
```

## 🆘 常见问题

### Q1: 我不知道要做什么功能怎么办？

**A:** 问 AI！

```
"我不确定接下来要做什么，你能帮我分析一下现在缺少什么功能吗？"

AI 会分析当前项目，给出建议。
```

### Q2: AI 做的不是我想要的怎么办？

**A:** 立即说！

```
"等等，我想要的不是这个，我想要的是 XXX"

AI 会立即调整方向。
```

### Q3: 功能太多，不知道先做哪个？

**A:** 问自己 3 个问题:

```
1. 哪个功能对用户最重要？
2. 哪个功能能快速看到效果？
3. 哪个功能是其他功能的基础？

然后告诉 AI 你的优先级。
```

### Q4: 感觉项目失控了怎么办？

**A:** 暂停，重新整理:

```
1. 看任务看板，了解当前状态
2. 关闭所有进行中的任务 (完成或暂停)
3. 只保留 1-2 个最重要的任务
4. 从最重要的开始

告诉 AI:
"我想重新整理任务优先级，请帮我整理当前的任务看板"
```

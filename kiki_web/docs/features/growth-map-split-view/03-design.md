# 成长地图分栏学习入口设计

## 设计结论

工程评审结论：通过。方案复用现有进度 API 与本地词条进度，只新增轻量快照缓存，不新增数据库结构。

## 页面结构

横屏采用约 `38:62` 的左右分栏：

```text
成长地图（选择与成长感） | 当前学习卡片（预览与进入学习）
```

- 左侧设置合理最小宽度，保留现有森林背景、路径节点和角色环境。
- 右侧使用安静的展示区域，只显示场景名称与一张尽可能大的正方形卡片。
- 窄屏无法稳定容纳分栏时，回退为当前地图页面，不在本次引入新的竖屏交互体系。

## 状态与交互

1. 页面加载后以 `restoredSceneIndex` 初始化当前选择。
2. 当前节点使用已有呼吸动画，并在首帧后滚动到左侧视口中部。
3. 点击节点：更新当前索引、持久化选择、滚动居中、切换右侧图片。
4. 右侧图片切换使用短时淡入，不引入横向卡片列表或翻页手势。
5. 点击右侧卡片：调用现有 `navigateToSceneDetail(scene, selectedIndex)`。
6. 节点不再锁定：待探索显示浅色嫩芽，已学显示亮色勾章和星数，当前选择保留呼吸环。
7. 本地进度一次批量读取；服务器全局进度在登录时强制同步，地图页按 06:00、17:00、20:00 窗口限流。

## 顺序与滚动

- 场景索引 `0` 位于顶部，后续场景依次向下。
- 使用普通纵向滚动，不再反转列表。
- 节点点击后通过控制器计算偏移，使目标节点尽量位于地图视口中部；首尾节点按滚动边界夹取。

## 验证策略

1. Widget 测试使用横屏视口，验证页面、节点名称和右侧当前卡片名称。
2. 点击第二个节点后，验证右侧内容切换且未触发学习路由。
3. 点击右侧卡片后，验证导航参数对应当前场景。
4. 运行 `flutter analyze --no-pub` 与相关 Flutter 测试。
5. 启动实际页面并保存横屏截图，检查地图辨识度、卡片完整度、溢出和点击热区。

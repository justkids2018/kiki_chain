# 三行文字组件规范

这个文件只定义标签卡片里的文字结构、层级和配色逻辑。

---

## ⚠️ 最高优先级：严格三行格式与脏文本禁令

**每张标签卡片必须且只能包含以下三行，顺序固定，不得增减：**

```
第 1 行：[拼音]     ← 只能是拼音，不得包含任何其他文字
第 2 行：汉字       ← 只能是该词的中文词语
第 3 行：English    ← 只能是该词的英文翻译
```

**绝对禁止出现在标签卡片上的内容：**
- `[cite:1]`、`[cite:2]`、`[cite:3]` 等任何引用标记
- `[ref:x]`、`[source:x]` 等任何来源标记
- 占位符、注释、序号、角标（如 `¹`、`²`、`[1]`、`(1)`）
- 大括号、方括号（除拼音本身的 `[pinyin]` 格式外）
- 任何超出三行格式以外的额外文字

**第 1 行格式铁律：**
- 第 1 行 = 拼音，形如 `[kè běn]` 或 `[jiǎng tái]`
- 拼音必须带中括号
- 第 1 行只有拼音，绝不允许把 `[cite:x]` 或任何其他文本放在拼音行

---

## 内容结构

默认使用三行格式，并保持顺序固定：

1. `[pinyin]`（仅拼音，带声调，带中括号）
2. `hanzi`（汉字，最大最粗）
3. `english`（英文翻译，较小）

## 必须规则

- 拼音必须带中括号，例如 `[kè běn]`
- 汉字必须是主视觉焦点
- 英文默认保留，但字号更小
- 三行文字必须使用同一文字主色系
- 不要把英文单独换成另一种颜色
- 层级只通过字号、字重、行距来区分

## 颜色逻辑

- 文字主色应优先来自场景主题色或环境强调色
- 文字颜色必须经过压暗处理，保证稳定和可读性
- 文字颜色必须与暖白卡片底形成明显区分
- 不允许文字颜色过浅、发虚、或与卡片底色接近

## 推荐方向

- 可使用深蓝灰、灰绿蓝、柔和深绿灰等儿童友好的稳定色相
- 汉字可以最粗最醒目，拼音和英文相对收一点，但不要换色

## 禁止项

- 禁止三行文字各用不同颜色
- 禁止英文颜色过跳或过亮
- 禁止浅色文字贴近暖白卡片底色
- 禁止在任何一行中出现 `[cite:x]`、`[ref:x]` 或任何引用痕迹
- 禁止在拼音行以外放置任何方括号内容（`[pinyin]` 格式本身除外）

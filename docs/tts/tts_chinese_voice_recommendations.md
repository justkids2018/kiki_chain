# 中文音色推荐清单（Sherpa-ONNX / Aishell3）

## 1. 目的

本文件用于统一记录当前项目可用的中文音色推荐方案，方便后续快速选型、切换和回归验证。

适用范围：

1. 当前项目使用的本地中文 TTS 模型（Aishell3 多说话人）
2. 学习卡片场景（儿童学习、互动点击朗读）

---

## 2. 当前项目基线

当前项目中文模型：

1. `vits-zh-aishell3`
2. 说话人由 `sid` 控制

当前代码默认（基线）：

1. `sid = 0`
2. 用途：更偏“常规普通话”

---

## 3. 推荐音色清单（先试听再定）

说明：以下 `sid` 为推荐试听集合，按“学习场景”优先顺序列出。

| 推荐级别 | sid | 场景建议 | 主观风格描述 |
|---|---:|---|---|
| A | 0 | 默认首选 | 常规普通话，稳妥中性，适合长期使用 |
| A | 21 | 儿童内容朗读 | 较柔和，听感友好 |
| A | 33 | 互动教学 | 清晰度较好，节奏自然 |
| B | 41 | 活泼场景 | 偏明亮，风格更“轻” |
| B | 45 | 绘本/故事 | 语气更温和 |
| B | 66 | 规则文本（数字日期） | 吐字稳定，适合说明类内容 |
| C | 99 | 差异化备选 | 可作为风格对比，不建议直接默认 |

备注：

1. 上述为“推荐试听集合”，不是官方音质排名。
2. 最终仍以你们业务试听结果为准（儿童接受度、疲劳感、清晰度）。

---

## 4. 最终推荐（当前项目）

综合“稳定性 + 普通话标准 + 学习场景”建议：

1. 默认：`sid = 0`
2. 儿童场景备选：`sid = 21` 或 `sid = 33`

建议落地策略：

1. 先上线 `sid = 0`
2. 如果需要更明显儿童感，再切到 `sid = 21`
3. 保留一个回退档（`sid = 0`）

---

## 5. 切换位置（代码）

中文音色 `sid` 在以下文件设置：

1. `kiki_web/lib/core/speech/local_speech_service.dart`

对应常量：

1. `_zhChildLikeSid`

示例：

- `static const int _zhChildLikeSid = 0;`

---

## 6. 快速 A/B 验证流程（建议）

固定 5 句测试文案，每个 `sid` 连续试听，记录主观分数（1~5）：

1. 清晰度（字是否清楚）
2. 自然度（是否机械）
3. 儿童友好度（是否温和）
4. 长听疲劳度（是否刺耳）
5. 场景匹配度（是否适合学习卡片）

建议先测：

1. `sid = 0`
2. `sid = 21`
3. `sid = 33`

若差异不明显，保持 `sid = 0`。

---

## 7. 后续扩展建议

如果后续想要更明显“儿童音色”且不依赖单一 `sid`：

1. 评估替换中文模型（例如其他中文多说话人模型）
2. 增加运行时音色配置（仅运营开关，不暴露给终端用户）
3. 以包体和性能为前提，避免引入过重模型

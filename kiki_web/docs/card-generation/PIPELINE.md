## Step 1：选题定词

### 输入
- 场景主题（如：图书馆、厨房、动物园）
- 所属分类（日常生活 / 游乐场景 / 数字认知 / 字母认知 / 传统节日）

### 输出
词汇表（通常 8 个物品，但以当前 md 声明的 N 为准）：

| 序号 | 中文 | 拼音 | 英文 | 音标 |
|------|------|------|------|------|
| 1 | 书 | shū | Book | /bʊk/ |
| 2 | 笔 | bǐ | Pen | /pɛn/ |
| 3 | 尺子 | chǐ zi | Ruler | /ˈruːlər/ |
| 4 | 橡皮 | xiàng pí | Eraser | /ɪˈreɪsər/ |
| 5 | 书包 | shū bāo | Backpack | /ˈbækpæk/ |
| 6 | 地球仪 | dì qiú yí | Globe | /ɡloʊb/ |
| 7 | 铅笔盒 | qiān bǐ hé | Pencil Case | /ˈpɛnsəl keɪs/ |
| 8 | 剪刀 | jiǎn dāo | Scissors | /ˈsɪzərz/ |

### 选词原则
- 适合 3-6 岁儿童认知
- 物品具象化、可绘制（避免抽象概念）
- 同一场景内物品不重复
- 中英文均为常用词汇

## Step 2：生成图片

### 输入
- 词汇表（来自 Step 1）
- Prompt 模板（见 [PROMPT.md](./PROMPT.md)）
- 替换变量：`[SCENE_THEME]`、`[COLOR_PALETTE]`

### 操作
1. 打开 Banana (Google AI 图片生成)
2. 填入完整 Prompt（替换变量后）
3. 生成图片，检查是否满足要求

### 输出
一张场景学习图，满足：
- 正方形 1:1，分辨率 1024×1024
- 等距投影 3D 风格
- N 个物品清晰独立、间距合理
- 每个物品旁有三行标注卡片（拼音 + 汉字 + 英文）
- 右上角 "Hi Kiki" 品牌标记
- 3D 卡通箭头指向物品

### 质量检查
- [ ] N 个物品全部可见且清晰
- [ ] 标注卡片文字可读（拼音声调正确）
- [ ] 箭头不交叉
- [ ] 整体风格统一，色彩明亮

---

## Step 3：标注热区

### 输入
- 生成的场景图片（来自 Step 2）
- 词汇表（来自 Step 1）

### 操作
对图片中的每个词汇标注热区矩形区域（4 个顶点坐标）。

真实场景模式推荐采用“双热区”标注：
- `card` 热区：标签卡片区域，必须优先保证
- `object` 热区：物体主体区域，只有在主体清晰独立时才添加

**方法 A：手动标注**
1. 用图片编辑工具（如 Figma / PS / 在线标注工具）打开图片
2. 先框选每个词对应的标签卡片区域
3. 再评估是否需要补充物体主体区域
4. 记录左上角 `(x1, y1)` 和右下角 `(x2, y2)`
5. 转换为 4 点格式：`[(x1,y1), (x2,y1), (x1,y2), (x2,y2)]`

**方法 B：AI 辅助标注（未来自动化）**
1. 将图片 + 词汇表输入视觉 AI
2. AI 识别物品位置并输出坐标
3. 人工校验坐标准确性

### 输出
每个词的热区坐标：

```
词「书」card 热区: (200, 300) → (450, 550)
  coordinate: [{x:200,y:300}, {x:450,y:300}, {x:200,y:550}, {x:450,y:550}]

词「书」object 热区: (240, 420) → (410, 520)
  coordinate: [{x:240,y:420}, {x:410,y:420}, {x:240,y:520}, {x:410,y:520}]
```

### 标注规则
- 每个词至少保留 1 个稳定可点区，优先为 `card` 热区
- `object` 热区只覆盖物体主体 + 10-15% 留白，不吞并邻近目标物
- 相邻不同词的热区不重叠
- 坐标不超出图片边界 (0~1024, 0~1024)

## Step 4：组装上线

### 输入
- 词汇表 + 坐标（来自 Step 1 & 3）
- 场景图片（来自 Step 2）

### 操作

#### 4.1 组装 JSON
按 [JSON_SPEC.md](./JSON_SPEC.md) 格式，将词汇信息和坐标合并：

```json
[
  {
    "type": "chinese",
    "id": "chinese_01",
    "index": 1,
    "text": "书",
    "text_pinyin": "shū",
    "text_english": "Book",
    "text_phonetic": "/bʊk/",
    "regions": [
      {
        "region_type": "card",
        "coordinate": [
          { "x": 200, "y": 300 },
          { "x": 450, "y": 300 },
          { "x": 200, "y": 550 },
          { "x": 450, "y": 550 }
        ]
      },
      {
        "region_type": "object",
        "coordinate": [
          { "x": 240, "y": 360 },
          { "x": 410, "y": 360 },
          { "x": 240, "y": 520 },
          { "x": 410, "y": 520 }
        ]
      }
    ]
  }
]
```

#### 4.2 上传图片
- 图片上传至 CDN（通过 Admin 后台图片上传功能）
- 获取 CDN URL

#### 4.3 创建/更新场景
通过 Admin 后台 → 场景管理：
- 设置 `interactive_image` = CDN URL
- 设置 `items_data` = 上述 JSON

#### 4.4 验证
先做 H5 叠加校验，再做移动端点击验证：

1. 打开 `hotspot-preview.html`，加载本次图片与 JSON，核对 card/object 区域是否对齐真实画面
2. 保存 1 张对照截图（用于回溯）
3. 在移动端打开场景，依次点击每个词的卡片区和物体区

校验清单：
- [ ] 每个词至少有 1 个热区可正确点击
- [ ] 若配置了 `object` 热区，点击物体主体也能触发同一词条
- [ ] 学习卡片展示正确（汉字 + 英文）
- [ ] TTS 发音正常
- [ ] 热区位置精准，不偏移

注：若运行时仍使用旧的扁平 region 结构，可在 repository 层将 `regions` 展平后再渲染。

## Step 0：先落目录（强制推荐）

执行前请先确认规则分层：

- 统一规则入口：`card-promp-rule/RULES.md`

原则：
- 写死规则不改语义，仅允许补充说明。
- 场景强化可迭代，但不得覆盖写死规则。
- 生成脚本只做组装，不发明新规则。

在开始生图前，先按统一目录创建卡片资产位：

```text
kiki_web/doc/card-generation/scene-info/
  <scene_slug>/
    <card_slug>/
      <card_slug>.jpg|png|webp
      <card_slug>.json
      prompt.md
```

规范：
- 图片和 JSON 文件名必须一致（同一个 `card_slug`）
- `<card_slug>.md` 是唯一可信 Prompt；`prompt.md` 只做兼容，必须与 `<card_slug>.md` 完全一致
- 校验页默认可按 `baseRoot + scene_slug + card_slug` 自动拼路径

推荐执行顺序：
1. 先执行批量脚本，从 `SCENES.md` 生成标准目录和 Prompt
2. 按每张卡片目录生成图片并放入同目录
3. 通过 skills 生成 JSON 并放入同目录
4. 用 `hotspot-preview.html` 自动拼路径加载并验证
5. 验证通过后再同步到 `assets/images` 和 `assets/data`

对应脚本命令：

```bash
cd kiki_web

# 批量生成 4 场景全部学习卡片 Prompt（命名：kik_场景_01_功能.md）
python3 scripts/card_generation/generate_prompts_from_scenes.py

# 需要单张初始化时使用
./scripts/card_generation/init_scene_card.sh <scene_slug> <card_slug> [image_ext]

# 校验通过后，同步到运行时 assets
./scripts/card_generation/sync_scene_card_assets.sh <scene_slug> <card_slug> [image_ext]
```

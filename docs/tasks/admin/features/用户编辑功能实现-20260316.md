# 用户管理编辑功能实现文档

**实现时间**: 2026-03-16
**功能**: 为管理后台添加用户编辑功能

---

## 📋 需求

1. 增加对用户的修改功能
2. 可修改项包括：
   - 用户名称（昵称）
   - 密码
   - VIP 状态

---

## 🔧 后端实现

### 1. API 路径定义

**文件**: `kiki_server/src/framework/bootstrap/api_paths.rs`

```rust
pub const ADMIN_USER_UPDATE: &'static str = "/api/v1/admin/users/{id}/update";
```

### 2. 路由配置

**文件**: `kiki_server/src/framework/bootstrap/routes/admin.rs`

```rust
.route(
    ApiPaths::ADMIN_USER_UPDATE,
    patch(admin_update_user_handler).with_state(app_state.clone()),
)
```

### 3. 更新用户 Handler

**请求 DTO**:
```rust
#[derive(Debug, serde::Deserialize)]
struct UpdateUserRequest {
    name: Option<String>,
    password: Option<String>,
    is_vip: Option<bool>,
}
```

**Handler 实现**:
- 动态构建 SQL UPDATE 语句
- 只更新提供的字段
- 正确处理 boolean 类型的参数绑定
- 返回更新结果

### 4. API 端点

```
PATCH /api/v1/admin/users/{id}/update
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "新昵称",
  "password": "新密码",
  "is_vip": true
}
```

**响应**:
```json
{
  "success": true,
  "data": {
    "uid": "user_id"
  },
  "message": "更新成功"
}
```

## 🎨 前端实现

### 1. API 接口定义

**文件**: `kiki_admin/src/api/users.ts`

```typescript
export interface UpdateUserRequest {
  name?: string
  password?: string
  is_vip?: boolean
}

export const userAPI = {
  update(id: string, data: UpdateUserRequest) {
    return request.patch(`/api/v1/admin/users/${id}/update`, data)
  }
}
```

### 2. 用户管理页面更新

**文件**: `kiki_admin/src/views/Users.vue`

**新增功能**:
1. ✅ 编辑按钮（每行添加）
2. ✅ 编辑对话框
3. ✅ 表单验证
4. ✅ 密码可选更新（留空则不修改）
5. ✅ VIP 状态开关
6. ✅ 更新成功后自动刷新列表

**表单字段**:
- 用户 ID（只读）
- 昵称（必填，2-50 字符）
- 密码（可选，6-20 字符）
- VIP 状态（开关）

## 📊 数据库字段映射

| 前端字段 | 后端字段 | 数据库字段 | 类型 |
|---------|---------|-----------|------|
| name | name | nickname | VARCHAR(50) |
| password | password | password_hash | VARCHAR(255) |
| is_vip | is_vip | is_vip | BOOLEAN |

**注意**:
- 数据库中没有 `email` 字段，因此不支持邮箱修改
- 密码直接存储为明文（生产环境应使用哈希）

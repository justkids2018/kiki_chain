# scene_05_入学准备 - 已停更（DEPRECATED）

⚠️ **本场景已停更，不再生成新卡片，不再被 index 引用。**

## 停更原因

本场景早期 6 张卡片（家庭成员 / 身体动作 / 情绪礼貌 / 天气四季 / 空间方位 / 生活自理）存在以下问题：

- 部分词条偏向**抽象概念**（情绪、方位、动作、自理），不符合 3-6 岁孩子"看见即懂、张嘴就说"的认知特点。
- 卡片之间主题跨度过大（家庭/动作/情绪/天气/方位/自理），不构成可叠加学习的统一场景体验。
- 与新版 `RULES.md` 中"词表选词原则（3-6 岁友好）"硬规则冲突。

## 替代方案

新场景 `scene_05_中国节日` 已创建，使用具体节日食物 / 标志物 / 活动道具作为词条，更符合幼儿认知规律。

## 现有内容处理

- 现存 6 张卡的资源**保留作为历史参考**，不删除。
- 不再写入 `scene-info/index.json`，不再纳入新一轮卡片生成 / 上传计划。
- 如需复用其中物品（书包、苹果、雨伞等），请把单个物品迁到新的具象主题卡上重新组合。

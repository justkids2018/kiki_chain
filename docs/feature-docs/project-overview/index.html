项目总结

Hi Kiki 的核心不是一组孤立的识字页面，而是一条完整的内容业务链：运营端生产主题化学习卡片，儿童在横屏场景中互动学习，系统沉淀进度与成长数据，VIP 权益承接高级内容，品牌站完成产品介绍、下载和版本触达。

学习体验场景图、热区、中英文词条、音频和笔顺组合成多感官学习过程。
内容运营主题、卡片、词条和资源可由后台维护，支持持续扩展内容。
成长记录学习行为形成进度明细和用户汇总，为家长观察成长提供依据。
商业闭环根据地区、平台和渠道匹配订阅产品，订单确认后发放 VIP 权益。

用户与价值

用户核心任务产品价值
儿童选场景、点物体、听发音、认词语、练汉字用探索代替单纯记忆，降低学习门槛
家长管理账号、查看成长、处理订阅与反馈了解学习结果并获得持续内容
运营人员维护主题、卡片、热区、资源与反馈无需频繁发布 App 即可扩展内容

关键规则

  • 身份失效时，不开放个人记录、资料和权益能力。
  • 图片或音频单项失败时采用局部降级，不让整个学习流程崩溃。
  • 学习进度允许安全重试；同一用户、同一卡片的结果应合并而非冲突。
  • 订阅确认必须幂等，任何重试不得重复发放权益。
  • 内容删除需保护关联词条、历史进度与业务可追溯性。

范围与验收

当前范围

覆盖身份、场景式学习、双语与音频、汉字书写、成长记录、VIP 订阅、用户反馈、内容后台和品牌下载站；不包含实时课堂、班级教务和第三方内容交易市场。

核心验收

  • 有效登录用户能从主题进入卡片并完成互动学习。
  • 点击有效热区会展示正确词条，音频可用时能正常播放。
  • 学习结束后进度可保存，并在成长页正确汇总。
  • 后台新增合规内容后，移动端能按发布规则读取。
  • 支付确认成功后权益更新，重复确认不重复发放。

风险与演进

发布状态建议增加草稿、校验、发布、停用生命周期，避免“保存即上线”。
契约一致性共享接口文档仍有历史口径，应与实际路由和客户端调用逐项对齐。
离线与多设备统一学习事件和幂等规则，为断网重试与多设备同步打基础。
儿童数据安全坚持最小采集、最小暴露、安全存储和可审计原则。

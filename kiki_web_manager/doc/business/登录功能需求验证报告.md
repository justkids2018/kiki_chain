### 问题2：密码在内存中明文传递（🔴 Critical - 安全风险）

**问题描述**：
密码从Controller传递到Repository时仍是明文，存在内存泄漏风险。

**当前实现流程**：
```
1. 用户输入密码（明文）
   ↓
2. AuthController.login()
   - loginPasswordController.text（明文）
   ↓
3. 传递给Repository
   - _authRepository.login(identifier, password)  // 明文传递
   ↓
4. AuthRepositoryImpl.login()
   - 此时才SHA256加密
```

**安全风险**：
- ⚠️ 明文密码在Dart内存中停留时间过长
- ⚠️ 如果Controller层出现异常，明文密码可能被日志记录
- ⚠️ 不符合安全编码最佳实践

**代码位置**：
- 明文传递：`auth_controller.dart:124-135`
- 加密位置：`auth_repository_impl.dart:45`

**修复建议**：
```dart
// 在Controller层直接加密，避免明文传递
Future<bool> login() async {
  if (!loginFormKey.currentState!.validate()) {
    return false;
  }

  try {
    EasyLoading.show(status: '登录中...');

    final identifier = loginIdentifierController.text.trim();
    // ✅ 立即加密，不传递明文
    final encryptedPassword = CryptoUtils.sha256Encrypt(loginPasswordController.text);

    // ✅ 传递加密后的密码
    final user = await _authRepository.login(identifier, encryptedPassword);

    // ... 后续逻辑
  }
}

// Repository接口文档需更新
/// 用户登录
///
/// 参数:
/// - [phone] 手机号（11位数字）
/// - [encryptedPassword] 密码（已SHA256加密）✅ 明确标注
Future<User?> login(String phone, String encryptedPassword);
```

### 问题5：Token自动刷新未实现（🟡 Medium）

**问题描述**：
API文档建议Token过期前1天自动刷新，但代码中只有刷新方法，没有自动触发逻辑。

**API文档建议**（doc/api/auth.md:217-226）：
```dart
// 在Token过期前1天自动刷新
final expiresAt = DateTime.parse(await storage.read(key: 'token_expires_at'));
final now = DateTime.now();

if (expiresAt.difference(now).inHours < 24) {
  // 刷新Token
  await refreshToken();
}
```

**当前实现**：
- ✅ 有`refreshAccessToken()`方法（auth_repository_impl.dart:225-258）
- ❌ 没有自动触发逻辑
- ❌ 没有定时检查Token过期时间

**影响**：
- 用户在Token过期后会被强制登出
- 用户体验不连贯（突然跳转登录页）

**修复建议**：
```dart
// 在AuthController初始化时启动定时检查
@override
void onInit() {
  super.onInit();
  _initializeAuthState();
  _startTokenRefreshTimer(); // ✅ 新增
}

/// 启动Token自动刷新定时器
void _startTokenRefreshTimer() {
  // 每小时检查一次
  Timer.periodic(Duration(hours: 1), (timer) async {
    if (!_isLoggedIn.value) {
      timer.cancel();
      return;
    }

    try {
      final expiresAtStr = await AppServices.instance.localStorage.getString('token_expires_at');
      if (expiresAtStr == null) return;

      final expiresAt = DateTime.parse(expiresAtStr);
      final now = DateTime.now();

      // Token过期前24小时自动刷新
      if (expiresAt.difference(now).inHours < 24) {
        AppLogger.info('Token即将过期，自动刷新...');
        await _authRepository.refreshAccessToken();
      }
    } catch (e) {
      AppLogger.error('Token自动刷新失败', e);
    }
  });
}
```

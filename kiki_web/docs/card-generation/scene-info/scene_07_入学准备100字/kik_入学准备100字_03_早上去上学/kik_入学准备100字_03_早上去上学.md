# 早上去上学 — 入学准备100字学习卡片 Prompt

> 分类：入学准备100字
> 主题序号：7.3
> 目标：在出门上学场景中认识常见物品、时间和动作

---

```text
**早上去上学** (主题): Hi Kiki

### I. Canvas & Style Lock
- Target age: 3-6 years old
- Exact 1024x1024 square, premium miniature toy diorama
- Warm morning light, home doorway and school-going atmosphere

### II. Scene Background
Create a warm home doorway scene in the morning. Kiki carries a schoolbag, Yuki stands nearby, Mimi follows them. A door, shoes, small car, umbrella stand, and morning sun create the story of going to school.

### III. Character Cast
Use Mimi + Yuki + Kiki. Mother can appear as unlabeled background support, but only if she does not crowd the targets.

### IV. 10 Target Vocabulary Objects
- [shū bāo] / 书包 / Schoolbag (/ˈskuːlbæɡ/)
- [mén] / 门 / Door (/dɔːr/)
- [xié] / 鞋 / Shoes (/ʃuːz/)
- [chē] / 车 / Car (/kɑːr/)
- [yǔ sǎn] / 雨伞 / Umbrella (/ʌmˈbrelə/)
- [zǎo] / 早 / Morning (/ˈmɔːrnɪŋ/)
- [lái] / 来 / Come (/kʌm/)
- [qù] / 去 / Go (/ɡoʊ/)
- [zǒu] / 走 / Walk (/wɔːk/)
- [wǒ] / 我 / Me (/miː/)

Object placement map:
1. 书包 — Kiki's clearly visible schoolbag.
2. 门 — large home door behind the children.
3. 鞋 — pair of shoes near the doorway.
4. 车 — small toy-like school car outside.
5. 雨伞 — umbrella in a stand near the door.
6. 早 — morning sun icon or soft sunrise clock near window.
7. 来 — small path arrow or gesture of Mimi coming toward Kiki.
8. 去 — visible walkway direction toward school gate.
9. 走 — Kiki's walking pose with one foot forward.
10. 我 — Kiki as the self anchor, label points to Kiki.

Critical placement rules:
- Action words must be anchored to visible movement or directional signs.
- 早 must not be a floating abstract word; use sun/clock visual anchor.
- 来 and 去 labels must point to clear direction/action anchors, not random empty space.

### V. Label Cards
- [shū bāo] / 书包 / Schoolbag
- [mén] / 门 / Door
- [xié] / 鞋 / Shoes
- [chē] / 车 / Car
- [yǔ sǎn] / 雨伞 / Umbrella
- [zǎo] / 早 / Morning
- [lái] / 来 / Come
- [qù] / 去 / Go
- [zǒu] / 走 / Walk
- [wǒ] / 我 / Me

### VI. Arrows
- 书包 arrow -> lands on schoolbag body.
- 门 arrow -> lands on door panel.
- 鞋 arrow -> lands on shoes.
- 车 arrow -> lands on car body.
- 雨伞 arrow -> lands on umbrella canopy or handle.
- 早 arrow -> lands on morning sun/clock anchor.
- 来 arrow -> lands on Mimi coming path/gesture anchor.
- 去 arrow -> lands on walkway direction sign toward school.
- 走 arrow -> lands on Kiki walking legs/pose.
- 我 arrow -> lands on Kiki's upper body.

### VII. Branding Badge
- Top-right corner: Hi Kiki

### VIII. Production Notes
- Recommended as a new original asset.
- Can later connect to school/campus theme but keep vocabulary easier than classroom cards.
```

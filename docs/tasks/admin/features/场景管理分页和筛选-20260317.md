### 3. 添加 Use Case 方法

**文件**: `kiki_server/src/core/use_cases/scene/admin_scene.rs`

添加 `list_scenes_by_category` 方法：
```rust
pub async fn list_scenes_by_category(
    &self,
    page: i64,
    page_size: i64,
    category_id: Option<&str>,
) -> Result<(Vec<Scene>, i64)> {
    let page = page.max(1);
    let page_size = page_size.clamp(1, 100);

    match category_id {
        Some(cat_id) => {
            // 获取该分类下的所有场景
            let all_scenes = self.repo.find_scenes_by_category(cat_id).await?;
            let total = all_scenes.len() as i64;

            // 手动分页
            let offset = ((page - 1) * page_size) as usize;
            let scenes: Vec<Scene> = all_scenes
                .into_iter()
                .skip(offset)
                .take(page_size as usize)
                .collect();

            Ok((scenes, total))
        }
        None => self.repo.find_all_scenes(page, page_size).await,
    }
}
```

const fetchScenes = async () => {

## 📊 API 参数说明

### 请求参数
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | number | 否 | 1 | 页码（从 1 开始） |
| pageSize | number | 否 | 20 | 每页数量（1-100） |
| categoryId | string | 否 | - | 分类 ID（为空则查询所有） |

### 响应数据
```typescript
{
  success: true,
  data: {
    total: 8,        // 总数
    page: 1,         // 当前页
    page_size: 10,   // 每页数量
    scenes: [...]    // 场景列表
  }
}
```

## 💡 技术要点

1. **后端分页**: 使用 `page` 和 `page_size` 参数
2. **分类筛选**: 当提供 `category_id` 时，先查询该分类的所有场景，然后在内存中分页
3. **前端分页**: 使用 Element Plus 的 `el-pagination` 组件
4. **状态管理**: 分类切换时重置页码，避免数据不一致

## 🎯 优化建议

1. **数据库层分页**: 当前分类筛选是在内存中分页，数据量大时可以优化为数据库层分页
2. **缓存**: 可以添加分类场景的缓存，减少数据库查询
3. **搜索功能**: 可以添加场景名称搜索功能
4. **排序**: 可以添加按创建时间、更新时间等排序功能

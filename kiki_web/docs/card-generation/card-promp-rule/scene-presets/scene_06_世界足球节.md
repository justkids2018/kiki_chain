# 场景预设：scene_06_世界足球节

本文件定义世界足球节类学习卡片的场景背景规则。

## 场景目标

- 画面应表达 3-6 岁孩子能理解的儿童足球节、校园小小足球赛、家庭观赛和社区庆祝氛围。
- 借用 2026 足球赛事热点，但不得出现 FIFA 标识、世界杯官方标识、真实国家队队徽、真实球星肖像或可识别商业赞助标志。
- 孩子必须是场景中的自然参与者：踢球、训练、守门、颁奖、加油或家庭观赛，不能只作为无关背景人物。
- 允许足球现场卡出现大量低细节背景观众：只能作为看台氛围，不贴标签、不画箭头、不替代 Mimi / Yuki / Kiki / Jack 主角色。
- 若用户明确要求足球角色观察卡，可把裁判、守门员、前锋等角色作为目标词；这些角色必须是清晰、玩具化、低冲突的场上目标人物，并与固定主角分层，避免误认。
- 视觉表现仍然遵守玩具微缩场景风格：圆润、温暖、可触摸感，不是真实摄影。

## 背景分层

- 前景：放置 2-3 个最大、最清晰、最容易点击的目标物体（通常是足球、球门、奖杯、训练道具或观赛物品）。
- 中景：放置主要人物动作和 3-4 个目标物体，让 Yuki / Kiki / Jack 与物品产生自然互动。
- 后景：放置场地、看台、家庭客厅、广场大屏等空间锚点；背景装饰不得抢目标物。

## 氛围

- 明亮、热闹、健康、运动感、友好协作，但不做真实赛事转播风格。
- 主色调建议：草坪绿、天空蓝、哨子黄、奖杯金、球衣白，整体保持明快且儿童友好。
- 避免拥挤、激烈冲撞、成人竞技压迫感、烟花爆炸、真实商业广告牌。

## 物品分布原则

- 每张卡的 8 个词条建议组合：
  - 2-3 个运动核心物：足球、球门、球网、手套等。
  - 2-3 个装备 / 训练物：球衣、球鞋、标志桶、秒表、水瓶等。
  - 1-2 个场地 / 活动物：角旗、记分牌、领奖台、大屏等。
  - 0-1 个庆祝 / 观赛物：奖杯、围巾、票根、喇叭等。
- 严禁把抽象概念（胜利、团队、冠军、热爱、荣誉）作为目标词条。
- 人物不作为目标词条；角色只能作为场景参与者。

## 易错防护

- 足球、圆形奖牌、贴纸等物体必须通过纹理、材质和位置区分。
- 球门、球网、球门柱不能合并：球门是整体框架，球网是网状织物，球门柱是单根立柱。
- 哨子和口哨如果分属不同卡，必须保持各自卡内清晰；同一卡不要同时出现。
- 标志桶、角旗、小旗、队旗需要通过形状和位置区分：标志桶是锥形训练桶，角旗/小旗/队旗是旗面。
- 观赛卡和广场卡可以热闹，但标签卡与箭头仍必须短、清楚、靠近目标物。
- 足球角色观察卡中，背景观众必须低细节、低权重；只有被词表列出的角色或物体能获得标签和箭头。

# Main Scene Cover Prompt Rules

本文件是 `main-scence` 一级场景主题卡片封面图的统一规则入口。

封面图只用于表达场景分类，不是学习卡片本体。因此需要借鉴 `card-promp-rule/RULES.md` 的稳定视觉约束，但不能继承学习卡片的 `8 个目标物体 / 8 张标签卡片 / 8 个箭头` 规则。

---

## 1) 输出定位

- 用途：一级场景分类卡片封面图。
- 输出格式：PNG。
- 画幅：7:9 竖版。
- 推荐分辨率：700 x 900。
- 适用年龄：3-6 岁。
- 画面必须完整使用竖版画布，无内框、无外框、无大面积空白边。
- 画面必须适合在 App 首页分类卡片中缩略展示，主体在小尺寸下仍可识别。

---

## 2) 从学习卡片继承的硬约束

- 必须是完整场景，不是物体陈列板、贴纸拼贴、海报或单物件展示。
- 必须具备明确前景 / 中景 / 后景分层。
- 必须固定出现 2 个可爱小女孩（姐妹）：
  - 姐姐：10 岁，长发散着。
  - 妹妹：4 岁，2 个马尾辫，优先裙装。
- 必须固定出现 1 只可爱的白色小猫。
- 姐姐、妹妹、白色小猫必须都清晰可见，且分布在不同景深层。
- 整体风格必须是 `premium miniature toy diorama`，圆润、饱满、柔和 3D 体积。
- 画面可以表现真实生活位置，但不能变成真实摄影、普通现场照或平面插画。
- 必须有自然接触阴影、柔和高光和清晰空间关系。
- 禁止大标题文字、品牌字样、标签卡片、箭头、脚注、引用标记。
- 禁止出现 `[cite:x]`、`[ref:x]`、`[source:x]`、上标序号、占位符或任何元信息文字。

---

## 3) 封面专用规则

- 每张封面只表达一个一级主题，主题识别必须强于局部物件细节。
- 可放入 5-9 个主题相关环境元素，但不要求逐个标注。
- 不要把元素平均铺满成清单，要形成一个真实可进入的场景。
- 构图需保留卡片裁切安全区：关键角色和主题锚点不要贴近边缘。
- 主题锚点要明确：
  - 日常生活：家居生活空间、厨房/客厅/卧室线索。
  - 游乐场景：滑梯、游乐设施、球池或户外活动线索。
  - 数字认知：数字积木、计数珠、点数游戏、学习角。
  - 字母认知：立体字母、自然拼读玩具、字母学习角。
  - 传统节日：中国传统节日装饰、灯笼、团圆食物、红金氛围。
  - 上学路上：安全街角、书包、斑马线、学校入口或晨光路径。
- 颜色可以贴合主题，但要保持儿童教育产品的干净、明亮和高级质感，避免单一色块堆满画面。

---

## 4) 生成前质检

- CANVAS CHECK：7:9 竖版，主体完整，无内框、无空白边、无裁切风险。
- SCENE CHECK：一眼能识别一级主题，不是物体陈列或海报拼贴。
- DEPTH CHECK：前景 / 中景 / 后景清晰，角色分层成立。
- CAST CHECK：恰好 2 个小女孩 + 1 只白色小猫；姐姐散发，妹妹双马尾。
- TEXT CHECK：画面内无大标题、无标签卡、无箭头、无引用或元信息文字。
- APP CARD CHECK：缩略展示时主题锚点和角色仍清晰可辨。

任一检查失败，必须重新生成。

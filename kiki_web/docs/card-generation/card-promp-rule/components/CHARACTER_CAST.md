# 角色与小猫统一 Prompt（公共引用）

本文件是学习卡片中"人物与宠物"的唯一公共规范。
所有场景 Prompt 必须直接引用本文件，不再重复手写角色描述。

## 固定约束（必须命中）

- 每张卡片固定出现 2 个小女孩，且为姐妹组合：
  - 姐姐：10 岁，长发散着。
  - 妹妹：4 岁，2 个马尾辫。
- 每张卡片固定出现 1 只可爱的白色小猫。
- 三个角色必须在画面内可见，不能被完全遮挡。
- 角色不可以替换成其他年龄、性别或动物组合。

## 穿搭与动作规则（固定 + 随机）

### 姐姐（10 岁）

- 固定：长发散发、整体可爱亲和。
- 默认：优先夏季风格。
- 随机：可根据场景季节切换为夏/秋/冬穿搭，服装可在裙子、背带裤、短袖套装、秋冬外搭之间变化。
- 冬季可选：可佩戴白色毛绒耳暖（耳罩）等保暖配件。
- 禁止：成人化妆造型、与季节明显冲突的极端服饰。

### 妹妹（4 岁）

- 固定：2 个马尾辫、年龄感幼态、优先裙装。
- 默认：优先夏季风格。
- 随机：可根据场景季节切换为夏/秋/冬穿搭，可在连衣裙、背带裙、轻薄背带裤等范围变化。
- 冬季可选：可佩戴白色毛绒耳暖（耳罩）等保暖配件。
- 禁止：单马尾、散发、成人化妆造型。

### 白色小猫（1 只）

- 固定：白色、可爱、清晰可见。
- 随机：动作可为伸懒腰、趴着、睡觉、盯看目标物体。
- 禁止：替换为其他颜色主猫、凶猛攻击姿态、恐怖风格。

## 场景自适应原则

- 角色动作和朝向要适配当前场景主题（课堂、家居、游乐、数学活动等）。
- 不强制每次服装一致，默认夏季；若场景更适合秋冬，可切换季节穿搭。
- 随机变化不能破坏"姐姐散发 + 妹妹双马尾 + 白色小猫"主识别。

## 标准引用片段（直接粘贴）

将以下段落原样注入到每张卡片 Prompt：

```md
角色与宠物（统一规则，必须满足）：
1) 画面固定包含 2 个可爱小女孩（姐妹）：
  - 姐姐：10 岁，长发散着。
  - 妹妹：4 岁，2 个马尾辫，优先裙装。
2) 画面固定包含 1 只可爱的白色小猫。
3) 穿搭默认夏季；可根据当前场景切换秋/冬风格，并在服装上随机变化（如裙子、背带裤、短袖套装、秋冬外搭），但不得破坏角色识别。
4) 冬季场景可随机加入白色毛绒耳暖（耳罩）等保暖配件。
5) 小猫动作允许随机（伸懒腰/趴着/睡觉/盯看），需自然融入场景并保持清晰可见。
```

## 质检清单（人物与宠物）

- 是否恰好 2 个小女孩 + 1 只白色小猫。
- 是否命中姐姐散发、妹妹双马尾。
- 是否符合场景季节（默认夏季，秋冬切换需合理）。
- 是否保持角色可见且不喧宾夺主。
- 是否符合当前场景语义与构图层次。
